macOS・Windows 向けの日本語入力システムです．
かな漢字変換には [azooKey](https://github.com/azooKey/AzooKeyKanaKanjiConverter) のエンジンと，ニューラル言語モデルの Zenzai を使用しています．

## 機能

- ライブ変換
- ツリー表示による変換候補の表示
- 文節の調整・分割・入力し直し
- AIによる打ち間違いの自動補正・もしかして予測変換 (macOSのみで有効)
- 英単語のつづりの自動補正
- 英字入力
- 日本語の表現連想変換機能
- 計算・郵便番号・日付と時刻・記号の変換
- 校正支援
- 手書き入力
- 辞書の取り込み
- キー操作とテーマのカスタマイズ
- アプリごとの入力設定
- 設定の同期とバックアップ
