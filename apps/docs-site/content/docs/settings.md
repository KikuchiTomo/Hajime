## ユーザー辞書と辞書の取り込み

ユーザー辞書には 10,000 単語まで登録可能で，読みには「gh」→ GitHub のように英字も使用可能です．Google 日本語入力・Microsoft IME・ATOK からエクスポートしたファイルも，そのままインポート可能です．

単語に適切な品詞を設定することで，文中でも前後の文脈に合わせて変換されます．

| 品詞 | 対象 |
|---|---|
| 名詞 | 一般的な名詞(既定) |
| 人名(姓のみ・名のみ・姓と名) | 人の名前 |
| 地名 | 地名・駅名 |
| 短縮よみ | 「おつ」→「お疲れさまでした」のような省略した読み．読み単独での変換時のみ表示され，文中では表示されない |
| 顔文字・記号 | 顔文字や記号 |
| その他 | 固有名詞・組織名・サ変名詞(「〜する」が付く単語)・形容動詞(「〜な」が付く単語)・副詞・感動詞 |

### 単語の登録

入力メニューの「単語の登録…」(Ctrl+F7)を選択することで，選択中の文字とその読みが入力された状態でユーザー辞書の画面を起動可能です．入力中に選択した場合は，入力中の語句と読みが入力されます．入力メニューは，Ctrl+F10 か Ctrl+変換 で入力位置にも表示可能です．

単語に設定したコメントは候補の横に表示され，クリックすることでコメントの内容を入力可能です．たとえば会社名のコメントに住所を設定することで，会社名の変換時に住所も入力可能です．

### インポートとエクスポート

| 操作 | 内容 |
|---|---|
| エクスポート | 読み・単語・品詞・コメントのタブ区切り形式で出力 |
| インポート | ほかの IME のファイルの品詞とコメントにも対応．品詞のない行は名詞として登録 |

ファイルを選択すると，インポート前に内容が表でプレビュー表示されます．

- 列の見出しには，各列の解釈結果(読み・単語・品詞・コメント)が表示されます．
- 品詞のない行は，品詞が「名詞」として強調表示されます．
- 形式エラーの行は，行番号に ⚠ が表示されます．
- 「〇単語をインポート」を押すまで，登録は実行されません．

インポートした辞書と連想辞書も同様です．

### 書式の展開

「書式の展開」(既定はオン)が有効な場合，単語に含まれる `{date}` などの書式が，変換時の値に展開されます．使用可能な書式は[単語と変換マクロの書式](#単語と変換マクロに書ける書き方)を参照してください．

たとえば読み「dt」に単語「`{datetime:YYYY-MM-DD hh:mm}`」を登録することで，「dt」で「2026-04-01 09:30」のような現在の日時を入力可能です．「にちじ」「いま」「きょう」などは，登録なしで日付や時刻に変換可能です．

設定画面では，書式をチップから選択して入力可能です．

| 操作 | 結果 |
|---|---|
| 単語欄の右の「{ }」ボタンを押す | 欄の下に書式のチップを表示(Esc か同じボタンで閉じる) |
| 単語欄に `{` を入力 | チップを表示し，続けて入力した文字で絞り込み(`{da` なら date・datetime・days) |
| チップをクリック | その書式を単語欄の入力位置に挿入 |

- 入力途中の書式は，クリックしたチップの書式に置換されます．変換(`|upper` など)と書式の記号(`YYYY` など)は，直前の書式の中に挿入されます．
- チップには現在の値が表示され，単語欄の下には展開後の結果がプレビュー表示されます．
- 閉じていない `{` や未定義の名前は，結果の右に ⚠ を付けてそのまま表示されます．
- チップの表示状態は，次回以降も保持されます．「書式の展開」がオフの場合は，ボタンとチップは表示されません．

### 辞書の取り込み

数十万単語の辞書も取り込み可能です．

| 項目 | 内容 |
|---|---|
| 形式 | 読み・単語・品詞のタブ区切りテキスト，SKK 辞書，macOS のユーザ辞書(plist) |
| 文字コード | UTF-8 / UTF-16 / Shift_JIS / EUC-JP |
| 上限 | 32 個，1 ファイル 256MB |
| 使用する場面 | 常に / 指定したアプリ / 文脈に応じて |

連想変換の辞書も取り込み可能です(8 個，1 ファイル 64MB まで)．

### 専門用語の辞書

医学・法律・情報技術などの専門用語を候補に表示するかどうかは，辞書のページの「専門用語」で選択可能です．専門用語の辞書は Hajime IME に同梱されており，JMdict と Wikidata の単語のうち，通常の辞書にないものを収録しています．

| 項目 | 既定 | 説明 |
|---|---|---|
| 専門用語辞書を使用 | オン | 専門用語の辞書全体の有効・無効 |
| 分野 | すべてオン | 分野ごとに有効・無効を選択(情報技術・医学・生物学・化学・物理学・数学・地学・天文学・工学・建築・法律・政治・経済・金融・ビジネス・言語学・哲学・思想・宗教・神話・音楽・美術・デザイン・料理・食品・スポーツ・囲碁・将棋・ゲーム・軍事・農林水産・芸能・映像・歴史・考古学) |

専門用語は同じ読みの一般的な単語より後ろに表示され，ツリー表示では選択中の候補の分野が表示されます．通常の辞書にも収録されている単語は，専門用語の辞書や分野をオフにしても候補に表示されます．

| 変換マクロ | 23 個(9 個がオン) | チェックを入れたマクロのみ表示．`{text}` が単語，`{reading}` が読み．100 個まで |
| 変換マクロを試す | | 入力した単語と読み(空欄の場合は「東京」)で，オンのマクロの結果を一覧表示．マクロの編集中は，そのマクロの結果のみ表示 |

標準のマクロは次のとおりで，括弧の 4 種類・読みの併記・小説投稿サイトのルビ(`|東京《とうきょう》`)・HTML のルビ・Markdown の太字とコードが既定でオンです．

| マクロ | 「東京」の結果 |
|---|---|
| `「{text}」` `『{text}』` `【{text}】` `（{text}）` `〈{text}〉` `“{text}”` `"{text}"` | 「東京」 など |
| `{text}（{reading}）` `{text}（{reading\|katakana}）` | 東京（とうきょう），東京（トウキョウ） |
| `{reading\|romaji}` | toukyou |
| `\|{text}《{reading}》` `[[rb:{text} > {reading}]]` | 小説投稿サイトと pixiv のルビ |
| `<ruby>{text}<rt>{reading}</rt></ruby>` `\ruby{{{text}}}{{{reading}}}` | HTML と LaTeX のルビ |
| `《《{text}》》` | 傍点 |
| `**{text}**` `` `{text}` `` `~~{text}~~` `#{text}` | Markdown の太字・コード・打ち消し線，ハッシュタグ |
| `[{text}](https://ja.wikipedia.org/wiki/{text\|url})` | Wikipedia へのリンク |
| `{text\|kansuji}` `{text\|daiji}` `{text\|comma}` | 単語中の数字を漢数字・大字・3 桁区切りに変換(「12000円」→ 一万二千円，壱万弐千円，12,000円)．数字を含まない単語では非表示 |

- 旧バージョンから更新した場合，新規のマクロはオフの状態で一覧の末尾に追加されます．削除済みのマクロは復元されません．
- 設定画面では，マクロ欄の右の「{ }」ボタンか，マクロ欄への `{` の入力で，[書式のチップ](#書式の展開)を表示可能です．チップをクリックするとその書式がマクロ欄に挿入され，欄の下に「試す単語」と読みでの結果がプレビュー表示されます．
- 一覧の「結果」列には，各マクロを「試す単語」と読み(未入力の場合は「東京」と「とうきょう」)に適用した結果が表示されます．

## 単語と変換マクロの書式 {#単語と変換マクロに書ける書き方}

変換マクロとユーザー辞書の単語で使用可能な書式の一覧です．分類は設定画面のチップと同じです．例は 2026 年 4 月 1 日(水) 9 時 30 分 15 秒(日本時間)の値です．

- 未定義の名前は，記述どおりの文字として入力されます．
- クリップボードや画面の内容を取得する書式と，プログラムを実行する書式はありません．

### 単語

変換マクロでのみ使用可能です．例は「東京」(読み とうきょう)の場合の値です．

| 書式 | 意味 | 例 |
|---|---|---|
| `{text}` | 選択中の単語 | 東京 |
| `{reading}` | 読み | とうきょう |
| `{reading\|katakana}` | 読みのカタカナ | トウキョウ |
| `{reading\|romaji}` | 読みのローマ字 | toukyou |

### 日時

| 書式 | 意味 | 例 |
|---|---|---|
| `{date}` | 今日の日付 | 2026/04/01 |
| `{time}` | 今の時刻 | 09:30 |
| `{datetime}` | 今の日時 | 2026/04/01 09:30:15 |
| `{date:M月D日(ddd)}` | 書式指定の日付 | 4月1日(水) |
| `{time:A K時m分}` | 書式指定の時刻 | 午前 9時30分 |
| `{utc}` | 協定世界時の日時 | 2026-04-01T00:30:15Z |
| `{unixtime}` | UNIX 時間(秒) | 1775003415 |

日時の名前(`date`・`time`・`datetime`・`utc`・`unixtime`・`holiday`・`season`・`greeting`・`days`・`age`)のあとには，加減算(`+1d`・`-30m`)と日付の指定(`@mon`〜`@sun`・`@1`〜`@31`・`@end`)を左から順に記述可能です．

| 対象 | 仕様 |
|---|---|
| 加減算の単位 | m 分・h 時間・d 日・w 週・M 月・y 年・b 営業日(土日と祝日を除く日)．1 か月後が月末を超える場合は月末 |
| 祝日 | 2020〜2099 年の祝日・振替休日・国民の休日 |
| 日数(`days`) | 過去の日付では負の数．年を省略した場合は次回のその日までの日数 |
| 時候の挨拶(`season`) | 1 月の「厳寒の候」から 12 月の「師走の候」まで |
| 時刻の挨拶(`greeting`) | 4〜10 時は「おはようございます」，11〜17 時は「こんにちは」，それ以外は「こんばんは」 |
| 変換 | 複数を連結すると左から順に適用 |
| 数字の変換(`kansuji` など) | 小数点以下の数字と 17 桁以上の数字は対象外．`circled` は 0〜50 のみ丸数字に変換 |
| 書式の記号 | 1 文字(`M`・`D`・`h` など)の場合は 1 桁の数に 0 を付けない．`'` で囲んだ文字は記号として解釈しない |

## ローマ字と記号

ローマ字の変換表には，ユーザ定義の変換を 500 個まで追加可能です(「wyi」→「ゐ」)．

記号の変換(「->」→「→」，「やじるし」→「→」)は，既定の変換の変更・無効化と，ユーザ定義の変換の追加が可能です．

## 絵文字と記号

| 項目 | 既定 | 選択肢・説明 |
|---|---|---|
| 絵文字と記号のパレット | オン | Control+Option+E・K・F(Windows は Ctrl+Alt+E・K・F)で絵文字・記号・顔文字のパレットを起動．キーはキー設定で変更可能 |
| 入力後にパレットを閉じる | オン | オフの場合は Enter で入力しても閉じない |
| 使用履歴を記録 | オン | よく使う文字の行と検索結果の順序に使用．端末内にのみ保存され，macOS は「使用履歴を消去」で消去可能．ピン留めと肌の色は消去の対象外 |
| パレットの列数 | 9 | 6〜14 |
| パレットの行数 | 6 | 一度に表示する行数．3〜12 |
| パレットのマスの大きさ | 36 pt | 28〜64 pt |
| パレットの倍率 | 100% | パレット全体(マス・文字・検索欄・説明)の拡大と縮小．50〜150%，10% 刻み |
| よく使う文字の行数 | 1 | 0〜4．0 の場合は非表示 |
| パレットに文字の説明を表示 | オン | パレットの下部に，選択中の文字の名前・読み・ショートコード・コードポイントを表示 |
| 説明に Unicode の名前を表示 | オン | 単一のコードポイントの文字は Unicode 名(😄 は「SMILING FACE WITH OPEN MOUTH AND SMILING EYES」)，国旗などの組み合わせの絵文字は CLDR の英語名(🇯🇵 は「flag: Japan」)を表示 |
| 説明に読みを表示 | オン | パレットの検索に使用可能な読みを表示 |

## キー設定

キーバインドは，状態・キー・コマンドの組み合わせで設定します．「プリセットを読み込む」から，標準・Windows 風・Mac 風・ATOK 風・Emacs 風・Vim 風のプリセットを適用可能です．

| 状態 | 意味 |
|---|---|
| いつでも | すべての状態 |
| 未入力 | 入力がない状態 |
| 入力中 | 読みの入力中 |
| 変換中 | 候補の選択中 |
| 英数 | 英数入力中 |

標準のキーバインドは[使い方](usage.md)を参照してください．

## 除外設定

アプリごとに入力モードの動作を設定可能です．エディタとターミナルは既定で登録されています．

| 動作 | 内容 |
|---|---|
| IME を使わない | 常に英数で入力 |
| IME オフ | アプリへの切り替え時に英数に変更．切り替え後は日本語入力にも変更可能 |
| IME オン | アプリへの切り替え時に日本語入力に変更 |
| IME のオン・オフを記憶 | そのアプリで最後に使用した入力モードを復元．記憶した入力モードは，ログアウトや再起動で消去 |
| 記号は半角 | 記号とスペースを半角で入力 |
| コマンドは英字 | 記号を半角にし，行頭のコマンドを英字のまま入力 |

「IME オフ」「IME オン」「IME のオン・オフを記憶」は，ほかの動作と組み合わせて同じアプリに登録可能です．

## 同期とバックアップ

同期先に Dropbox・Google Drive・iCloud Drive などのフォルダを指定することで，複数の端末間で設定と辞書を同期可能です．同期する項目も選択可能です．

| 既定 | 項目 |
|---|---|
| 同期する | 入力・キー設定・変換・補正・記号・ユーザー辞書・インポートした辞書 |
| このパソコンだけ | キー配列・外観・除外設定・統計 |

バックアップでは，すべての設定を JSON 形式でエクスポート・インポート可能です．
