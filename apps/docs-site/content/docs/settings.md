## 英語と日本語

英字で打った語を，英語のままにするか日本語にするかを決めます．

| 項目 | 既定 | 説明 |
|---|---|---|
| 前の単語で判別 | オン | 「make」のように両方に読める語を，前の単語に合わせて判別する |
| 不適切な変換を避ける | オン | |
| 常に英語にする単語 | なし | |
| 常に日本語にする単語 | なし | |
| 判別ルール | なし | 語と直前の文脈ごとに，英語と日本語のどちらにするかを指定する |

## ユーザー辞書と辞書の取り込み

ユーザー辞書には 10,000 語まで登録でき，読みには「gh」→ GitHub のような英字も使えます．Google 日本語入力・Microsoft IME・ATOK で書き出したファイルも，そのまま読み込めます．

単語ごとに品詞を正しく選んでおくと，文の中でも前後とつながりよく変換されます．

| 品詞 | 向いている語 |
|---|---|
| 名詞 | ふつうの名詞(既定) |
| 人名(姓のみ・名のみ・姓と名) | 人の名前 |
| 地名 | 地名・駅名 |
| 短縮よみ | 「おつ」→「お疲れさまでした」のような略した読み．読みだけを変換したときに出て，文の中では出ない |
| 顔文字・記号 | 顔文字や記号 |
| その他 | 固有名詞・組織名・サ変名詞(「〜する」が付く語)・形容動詞(「〜な」が付く語)・副詞・感動詞 |

入力メニューの「単語の登録…」(Ctrl+F7)を選ぶと，選択中の文字とその読みを入れた状態でユーザー辞書の画面が開きます．入力中に選んだときは，その語句と読みが入ります．入力メニューは，Ctrl+F10 か Ctrl+変換 で入力位置にも出せます．

単語に付けたコメントは候補の横に出て，押すとコメントの文字を入力できます．会社名に住所をコメントとして付けておけば，会社名を変換するついでに住所も入力できます．

書き出すファイルは，読み・単語・品詞・コメントのタブ区切りです．読み込むときは，ほかの IME のファイルの品詞とコメントも読み取り，品詞の無い行は名詞として登録します．

「単語に書いた日付や時刻などを入力時の値にする」(既定はオフ)をオンにすると，単語の中の次の書き方が，変換したときの値に置き換わります．それぞれの書き方がいま何になるかは，設定の画面で確認できます．

| 書き方 | 入るもの | 例 |
|---|---|---|
| `{date}` | 今日の日付 | 2026/04/01 |
| `{time}` | 今の時刻 | 09:30 |
| `{datetime:YYYY/MM/DD hh:mm:ss}` | 書式を決めた日時 | 2026/04/01 09:30:15 |
| `{datetime+1d:MM/DD}` | 日をずらした日付．`-7d` なら 7 日前 | 04/02 |
| `{time+30m}` | ずらした時刻．m 分・h 時間・d 日・w 週・M 月・y 年でずらす | 10:00 |
| `{date+1w@mon:M/D(ddd)}` | 来週の月曜．`@mon`〜`@sun` はその週の曜日，`@1`〜`@31` はその月の日，`@end` は月末 | 4/6(月) |
| `{date+3b:M/D(ddd)}` | 3 営業日後．`b` は土日と祝日を除いて数える | 4/6(月) |
| `{date:GGEE年M月D日\|kansuji}` | 漢数字の和暦．1 年は「元年」 | 令和八年四月一日 |
| `{date:FFFF年度 NN JJ}` | 年度・和風月名・干支 | 2026年度 卯月 丙午 |
| `{utc}` | 協定世界時の日時 | 2026-04-01T00:30:15Z |
| `{unixtime}` | UNIX 時間(秒) | |
| `{holiday:平日}` | 祝日の名前．祝日でなければ `:` のあとの文字(書かなければ何も入れない) | 平日 |
| `{season}` | その月の時候の挨拶 | 陽春の候 |
| `{greeting}` | 時刻に合った挨拶 | おはようございます |
| `{days:12/25}` | その日までの日数．`2027-03-31` のように年も書ける | 268 |
| `{age:1990-04-01}` | その日に生まれた人の満年齢 | 36 |
| `{uuid}` | UUID．入れるたびに変わる | |
| `{random:1-6}` | 範囲の中の整数．入れるたびに変わる | 4 |
| `{alnum:8}` | 英数字 8 文字．`{hex:8}` なら 16 進数．入れるたびに変わる | |
| `{pick:はい,いいえ}` | 並べたうちのどれか 1 つ．入れるたびに変わる | |
| `{date\|fullwidth}` | `\|` のあとの名前で変えた値 | ２０２６／０４／０１ |
| `{{ }}` | 「{」と「}」の文字そのもの | { } |

`|` のあとに書ける変換と日時の書式の記号は，[変換マクロと単語に書ける書き方](#変換マクロと単語に書ける書き方)を参照してください．

たとえば読み「dt」に単語「`{datetime:YYYY-MM-DD hh:mm}`」を登録すると，「dt」で「2026-04-01 09:30」のような今の日時を入力できます．「にちじ」「いま」「きょう」などは，登録しなくても日付や時刻に変換できます．

辞書の取り込みでは，数十万語の辞書も使えます．

| 項目 | 内容 |
|---|---|
| 形式 | 読み・単語・品詞のタブ区切りテキスト，SKK 辞書，macOS のユーザ辞書(plist) |
| 文字コード | UTF-8 / UTF-16 / Shift_JIS / EUC-JP |
| 上限 | 32 個，1 ファイル 256MB |
| 使用する場面 | 常に / 指定したアプリ / 文脈に合わせる |

連想変換の辞書も取り込めます(8 個，1 ファイル 64MB まで)．

### 専門用語の辞書

医学・法律・情報技術などの専門用語を候補に出すかどうかは，辞書のページの「専門用語」で選べます．専門用語の辞書は Hajime IME に同梱しており，JMdict と Wikidata の語のうち，通常の辞書に無いものだけを集めています．

| 項目 | 既定 | 説明 |
|---|---|---|
| 専門用語の辞書を使う | オン | オフにすると，専門用語の辞書を使わない |
| 使う分野 | すべてオン | 分野ごとにオン・オフを選ぶ(情報技術・医学・生物学・化学・物理学・数学・地学・天文学・工学・建築・法律・政治・経済・金融・ビジネス・言語学・哲学・思想・宗教・神話・音楽・美術・デザイン・料理・食品・スポーツ・囲碁・将棋・ゲーム・軍事・農林水産・芸能・映像・歴史・考古学) |

専門用語は同じ読みのふだんの語より後ろに並び，分岐図では選んでいる候補の分野が表示されます．通常の辞書にもある語は，専門用語の辞書や分野をオフにしても候補に出ます．

## コマンドと変換マクロ

| 項目 | 既定 | 説明 |
|---|---|---|
| 読みでコマンドを呼び出す | オフ | 登録した読みを変換すると候補に「▶ 名前」が並び，確定するとアプリ・Web ページ・ファイルを開く(macOS はショートカットも実行できる)．第 1 候補にはならない |
| コマンド | なし | 読み・名前・動作・行き先の組．200 個まで．このパソコンだけに保存し，同期や設定の読み込みの対象外 |
| 連想変換のキーで変換マクロを表示 | オフ | 変換中に連想変換のキーを押すと，選んでいる語を整えた形(「」で囲む・ルビを付けるなど)を「整形」に並べる |
| かなの語には読みを添える形を出さない | オン | 語が読みと同じ(「すし」「スシ」)とき，`{text}（{reading}）` やルビのように語と読みを並べる形を出さない |
| 変換マクロ | 23 個(9 個がオン) | チェックを入れた形だけを出す．`{text}` が語，`{reading}` が読み．100 個まで |
| 変換マクロを試す | | 入れた語と読み(空なら「東京」)で，オンの形の結果を並べる．形を書いている途中は，その形の結果だけを出す |

初めから入っている形は次のとおりで，括弧の 4 つ・読みを添える形・小説投稿サイトのルビ(`|東京《とうきょう》`)・HTML のルビ・Markdown の太字とコードがオンになっています．

| 形 | 「東京」の結果 |
|---|---|
| `「{text}」` `『{text}』` `【{text}】` `（{text}）` `〈{text}〉` `“{text}”` `"{text}"` | 「東京」 など |
| `{text}（{reading}）` `{text}（{reading\|katakana}）` | 東京（とうきょう），東京（トウキョウ） |
| `{reading\|romaji}` | toukyou |
| `\|{text}《{reading}》` `[[rb:{text} > {reading}]]` | 小説投稿サイトと pixiv のルビ |
| `<ruby>{text}<rt>{reading}</rt></ruby>` `\ruby{{{text}}}{{{reading}}}` | HTML と LaTeX のルビ |
| `《《{text}》》` | 傍点 |
| `**{text}**` `` `{text}` `` `~~{text}~~` `#{text}` | Markdown の太字・コード・打ち消し線，ハッシュタグ |
| `[{text}](https://ja.wikipedia.org/wiki/{text\|url})` | Wikipedia へのリンク |
| `{text\|kansuji}` `{text\|daiji}` `{text\|comma}` | 語の中の数字を漢数字・大字・3 桁区切りに(「12000円」→ 一万二千円，壱万弐千円，12,000円)．数字の無い語では出ない |

以前の版から更新すると，新しく増えた形はオフの状態で一覧の末尾に加わります．自分で消した形は元に戻りません．

### 変換マクロと単語に書ける書き方

次の書き方は，変換マクロと，日付や時刻などを入力時の値にするユーザー辞書の単語に使えます．未知の名前は，書いたとおりの文字で入力されます．クリップボードや画面の内容を読む名前や，プログラムを実行する名前はありません．

| 書き方 | 入る文字 |
|---|---|
| `{text}` `{reading}` | 選んでいる語とその読み(変換マクロだけ) |
| `{date}` `{time}` | 今日の日付(2026/11/12)と今の時刻(09:05)．`{date:M/D}` のように書式も書ける |
| `{datetime:YYYY年M月D日(ddd) hh:mm}` | 書式を指定した日時 |
| `{utc}` | 協定世界時(2026-11-12T00:05:00Z) |
| `{unixtime}` | UNIX 時間(秒) |
| `{holiday}` `{holiday:平日}` | 祝日・振替休日・国民の休日の名前．祝日でなければ空か，`:` のあとの文字．2020〜2099 年 |
| `{season}` | その月の時候の挨拶(1 月 厳寒の候 〜 12 月 師走の候) |
| `{greeting}` | 時刻の挨拶(4〜10 時 おはようございます，11〜17 時 こんにちは，ほかは こんばんは) |
| `{days:12/25}` `{days:2027-03-31}` | その日までの日数．過ぎた日は負の数．年を書かなければ次に来るその日 |
| `{age:1990-04-01}` | その日に生まれた人の今の満年齢 |
| `{uuid}` | UUID(大文字．小文字は `{uuid\|lower}`) |
| `{random:1-6}` | 範囲の中の整数 |
| `{alnum:8}` `{hex:8}` | 英数字と 16 進数(小文字)．1〜64 文字 |
| `{pick:A,B,C}` | `,` で区切ったうちのどれか 1 つ |
| `{{` `}}` | `{` と `}` そのもの |

日時の書式には次の記号を使い，`'…'` で囲んだ文字は記号として扱いません．

| 記号 | 意味 | 記号 | 意味 |
|---|---|---|---|
| `YYYY` `YY` | 年 | `hh` `h` | 時(24 時間制) |
| `MM` `M` | 月 | `KK` `K` | 時(12 時間制) |
| `MMMM` `MMM` | 英語の月(November，Nov) | `mm` `m` `ss` `s` | 分，秒 |
| `DD` `D` | 日 | `A` `AA` | 午前・午後，AM・PM |
| `dddd` `ddd` | 曜日(水曜日，水) | `GG` `E` | 元号と年(令和 8) |
| `EEEE` `EEE` | 英語の曜日(Wednesday，Wed) | `WW` `W` | ISO 8601 の週番号 |
| `DDDD` `DDD` | 年の何日目か | `Q` `ZZ` | 四半期，時間帯(+09:00) |
| `EE` | 元号の年．1 年は「元」(令和元) | `FFFF` `FF` | 年度(4 月始まり．2026，26) |
| `NN` | 和風月名(霜月) | `JJ` | 年の干支(丙午) |

日時の名前(`date`・`time`・`datetime`・`utc`・`unixtime`・`holiday`・`season`・`greeting`・`days`・`age`)のあとに，ずらす量と合わせる先を左から順に書けます．

| 書き方 | 意味 | 例 |
|---|---|---|
| `+1d` `-30m` | ずらす．単位は m 分・h 時間・d 日・w 週・M 月・y 年 | `{time+30m}` 30 分後，`{date+1M}` 1 か月後(月末を超えたら月末) |
| `+3b` `-1b` | 土日と祝日を除いた日でずらす | `{date+3b}` 3 営業日後，`{holiday+1d}` 明日の祝日 |
| `@mon` 〜 `@sun` | その週(月曜から日曜)の曜日 | `{date@fri}` 今週の金曜，`{date+1w@mon}` 来週の月曜 |
| `@1` 〜 `@31` `@end` | その月の日，月末 | `{date@end}` 今月末，`{date+1M@1}` 来月 1 日 |

`{text|upper}` のように `|` のあとに変換の名前を書くと，値を変換できます．複数書くと左から順に適用します．

| 変換 | 意味 |
|---|---|
| `upper` `lower` `capitalize` | 大文字，小文字，先頭だけ大文字 |
| `katakana` `hiragana` | カタカナ，ひらがな |
| `halfwidth` `fullwidth` `ascii` | 半角カタカナ，全角英数，半角英数 |
| `romaji` | ヘボン式のローマ字(「とうきょう」→ toukyou．「ん」は n) |
| `snake` `camel` `pascal` `kebab` | 英語の語の書き方(hello_world，helloWorld，HelloWorld，hello-world) |
| `url` | URL に入れる形(パーセントエンコード) |
| `length` | 文字数 |
| `kansuji` `kanjidigits` | 数字を漢数字に(2026 → 二千二十六，二〇二六) |
| `daiji` | 数字を大字に(12000 → 壱万弐千) |
| `comma` | 4 桁以上の数字を 3 桁ごとに区切る(1234567 → 1,234,567) |
| `circled` | 0〜50 の数字を丸数字に(3 → ③) |
| `html` | HTML に入れる形(`<` → `&lt;` など) |
| `base64` | UTF-8 の Base64 |

数字の変換は，小数点以下の数字と 17 桁以上の数字には適用しません．

## ローマ字と記号

ローマ字の変換表には，組み合わせを 500 個まで追加できます(「wyi」→「ゐ」)．

記号の変換(「->」→「→」，「やじるし」→「→」)は，既定の組み合わせの変更や無効化と，新しい組み合わせの追加ができます．

## 絵文字と記号

| 項目 | 既定 | 選択肢・説明 |
|---|---|---|
| 絵文字と記号のパレット | オン | Control+Option+E・K・F(Windows は Ctrl+Alt+E・K・F)で絵文字・記号・顔文字のパレットを開く．キーはキー設定で変更できる |
| 入力したらパレットを閉じる | オン | オフにすると，Enter で入力しても閉じない |
| パレットで使った文字を記録 | オン | よく使う文字の行と検索結果の順に使う．このパソコンの中にだけ保存し，macOS は「使った文字の記録を消去」で消去できる．ピン留めと肌の色は消去の対象外 |
| パレットの列数 | 9 | 6〜14 |
| パレットの行数 | 6 | 一度に表示する行の数．3〜12 |
| パレットのマスの大きさ | 36 pt | 28〜64 pt |
| よく使う文字の行数 | 1 | 0〜4．0 で表示しない |
| パレットに文字の説明を表示 | オン | パレットの下に，選んでいる文字の名前・読み・ショートコード・コードポイントを表示する |
| 説明に Unicode の名前を表示 | オン | 1 つのコードポイントの文字は Unicode の文字の名前(😄 は「SMILING FACE WITH OPEN MOUTH AND SMILING EYES」)，国旗などの組み合わせの絵文字は CLDR の英語の名前(🇯🇵 は「flag: Japan」)を表示する |
| 説明に読みを表示 | オン | パレットで探すときに使える読みを表示する |
| 説明にショートコードを表示 | オン | 「:smile:」のようなショートコードを表示する |
| 説明にコードポイントを表示 | オン | 「U+1F604」のようなコードポイントを表示する．顔文字には表示しない |

パレットの色と書体は，外観のテーマに合わせて変わります．

## キー設定

キー操作は，状態・キー・コマンドの組で設定します．標準・Windows 風・Mac 風・ATOK 風・Emacs 風・Vim 風のひな形から始められます．

| 状態 | 意味 |
|---|---|
| いつでも | すべての状態 |
| 入力文字なし | 何も入力していないとき |
| 入力中 | 読みを入力しているとき |
| 変換中 | 候補を選んでいるとき |
| 英数 | 英数入力のとき |

標準のキーは[使い方](usage.md)にまとめています．

## 除外設定

アプリごとに入力の扱いを決められます．エディタとターミナルは，初めから登録しています．

| 動作 | 内容 |
|---|---|
| IME を使わない | 常に英数で入力する |
| IME をオフ | アプリに切り替えるたびに英数にする．あとから日本語入力にも切り替えられる |
| IME をオン | アプリに切り替えるたびに日本語入力にする |
| IME のオンオフを記憶 | そのアプリで最後に使った入力モードに戻す．覚えた入力モードは，ログアウトや再起動で消える |
| 記号を半角 | 記号とスペースを半角で入力する |
| コマンドを英字 | 記号を半角にし，行の先頭のコマンドを英字のまま入力する |

IME をオフ・IME をオン・IME のオンオフを記憶は，ほかの動作と組み合わせて同じアプリに登録できます．

## 同期とバックアップ

同期のフォルダに Dropbox・Google Drive・iCloud Drive などのフォルダを指定すると，複数のパソコンで設定と辞書を同期でき，同期する項目も選べます．

| 既定 | 項目 |
|---|---|
| 同期する | 入力・キー設定・変換・補正・記号・ユーザー辞書・取り込んだ辞書 |
| このパソコンだけ | キー配列・外観・除外設定・統計 |

バックアップでは，すべての設定を JSON で書き出したり読み込んだりできます．
