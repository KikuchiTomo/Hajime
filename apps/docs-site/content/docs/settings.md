## ユーザー辞書と辞書の取り込み

ユーザー辞書には 10,000 語まで登録でき，読みには「gh」→ GitHub のような英字も使えます．Google 日本語入力・Microsoft IME・ATOK で書き出したファイルも，そのまま読み込めます．

単語ごとに品詞を正しく選んでおくと，文の中でも前後とつながりよく変換されます．

| 品詞 | 向いている語 |
|---|---|
| 名詞 | ふつうの名詞(既定) |
| 人名(姓のみ・名のみ・姓と名) | 人の名前 |
| 地名 | 地名・駅名 |
| 短縮よみ | 「おつ」→「お疲れさまでした」のような略した読み．読みだけを変換したときに出て，文の中では出ない |
| 顔文字・記号 | 顔文字や記号 |
| その他 | 固有名詞・組織名・サ変名詞(「〜する」が付く語)・形容動詞(「〜な」が付く語)・副詞・感動詞 |

入力メニューの「単語の登録…」(Ctrl+F7)を選ぶと，選択中の文字とその読みを入れた状態でユーザー辞書の画面が開きます．入力中に選んだときは，その語句と読みが入ります．入力メニューは，Ctrl+F10 か Ctrl+変換 で入力位置にも出せます．

単語に付けたコメントは候補の横に出て，押すとコメントの文字を入力できます．会社名に住所をコメントとして付けておけば，会社名を変換するついでに住所も入力できます．

書き出すファイルは，読み・単語・品詞・コメントのタブ区切りです．読み込むときは，ほかの IME のファイルの品詞とコメントも読み取り，品詞の無い行は名詞として登録します．

ファイルを選ぶと，取り込む前に中身が表で出ます．列の見出しはその列が何として読まれたか(読み・単語・品詞・コメント)で，品詞の無い行は品詞が注意の色の「名詞」に，形式エラーの行は行の番号に ⚠ が付きます．「〇単語をインポート」を押すまで何も登録しません．インポートした辞書と連想辞書も同じです．

「書式の展開」(既定はオン)がオンのあいだ，単語の中の `{date}` などの書き方が，変換したときの値に置き換わります．書き方は[単語と変換マクロに書ける書き方](#単語と変換マクロに書ける書き方)のとおりです．

設定の画面では，単語の欄のすぐ右の「{ }」のボタンを押すと，欄の下に書式のチップが開きます．単語の欄で `{` を打っても開き，続けて打った文字でチップを絞り込みます(`{da` なら date・datetime・days)．チップをクリックすると，その書き方が単語の欄の入力位置に入ります．打ちかけの書き方はチップの書き方に置き換わり，値の変え方(`|upper` など)と書式の記号(`YYYY` など)は，その前の書き方の中に入ります．Esc か同じボタンで閉じます．開いているかどうかは，次に設定の画面を開いたときも同じです．

チップにはいまの値が添えてあり，単語の欄のすぐ下には，その単語を入れたときの値が出ます．閉じていない `{` や知らない名前は，値の右に ⚠ を付けてそのまま示します．スイッチがオフのあいだは，ボタンもチップも出ません．

たとえば読み「dt」に単語「`{datetime:YYYY-MM-DD hh:mm}`」を登録すると，「dt」で「2026-04-01 09:30」のような今の日時を入力できます．「にちじ」「いま」「きょう」などは，登録しなくても日付や時刻に変換できます．

辞書の取り込みでは，数十万語の辞書も使えます．

| 項目 | 内容 |
|---|---|
| 形式 | 読み・単語・品詞のタブ区切りテキスト，SKK 辞書，macOS のユーザ辞書(plist) |
| 文字コード | UTF-8 / UTF-16 / Shift_JIS / EUC-JP |
| 上限 | 32 個，1 ファイル 256MB |
| 使用する場面 | 常に / 指定したアプリ / 文脈に応じて |

連想変換の辞書も取り込めます(8 個，1 ファイル 64MB まで)．

### 専門用語の辞書

医学・法律・情報技術などの専門用語を候補に出すかどうかは，辞書のページの「専門用語」で選べます．専門用語の辞書は Hajime IME に同梱しており，JMdict と Wikidata の語のうち，通常の辞書に無いものだけを集めています．

| 項目 | 既定 | 説明 |
|---|---|---|
| 専門用語辞書を使用 | オン | オフにすると，専門用語の辞書を使わない |
| 分野 | すべてオン | 分野ごとにオン・オフを選ぶ(情報技術・医学・生物学・化学・物理学・数学・地学・天文学・工学・建築・法律・政治・経済・金融・ビジネス・言語学・哲学・思想・宗教・神話・音楽・美術・デザイン・料理・食品・スポーツ・囲碁・将棋・ゲーム・軍事・農林水産・芸能・映像・歴史・考古学) |

専門用語は同じ読みのふだんの語より後ろに並び，分岐図では選んでいる候補の分野が表示されます．通常の辞書にもある語は，専門用語の辞書や分野をオフにしても候補に出ます．

## コマンドと変換マクロ

| 項目 | 既定 | 説明 |
|---|---|---|
| 読みでコマンドを実行 | オン | 登録した読みを変換すると候補に「▶ 名前」が並び，確定するとアプリ・Web ページ・ファイルを開く(macOS はショートカットも実行できる)．第 1 候補にはならない |
| コマンド | なし | 読み・名前・動作・対象の組．200 個まで．このパソコンだけに保存し，同期や設定の読み込みの対象外 |
| 連想変換のキーで変換マクロを表示 | オン | 変換中に連想変換のキーを押すと，選んでいる語を整えた形(「」で囲む・ルビを付けるなど)を「整形」に並べる |
| かなの単語は読み付きを省略 | オン | 語が読みと同じ(「すし」「スシ」)とき，`{text}（{reading}）` やルビのように語と読みを並べる形を出さない |
| 変換マクロ | 23 個(9 個がオン) | チェックを入れた形だけを出す．`{text}` が語，`{reading}` が読み．100 個まで |
| 変換マクロを試す | | 入れた語と読み(空なら「東京」)で，オンの形の結果を並べる．形を書いている途中は，その形の結果だけを出す |

初めから入っている形は次のとおりで，括弧の 4 つ・読みを添える形・小説投稿サイトのルビ(`|東京《とうきょう》`)・HTML のルビ・Markdown の太字とコードがオンになっています．

| 形 | 「東京」の結果 |
|---|---|
| `「{text}」` `『{text}』` `【{text}】` `（{text}）` `〈{text}〉` `“{text}”` `"{text}"` | 「東京」 など |
| `{text}（{reading}）` `{text}（{reading\|katakana}）` | 東京（とうきょう），東京（トウキョウ） |
| `{reading\|romaji}` | toukyou |
| `\|{text}《{reading}》` `[[rb:{text} > {reading}]]` | 小説投稿サイトと pixiv のルビ |
| `<ruby>{text}<rt>{reading}</rt></ruby>` `\ruby{{{text}}}{{{reading}}}` | HTML と LaTeX のルビ |
| `《《{text}》》` | 傍点 |
| `**{text}**` `` `{text}` `` `~~{text}~~` `#{text}` | Markdown の太字・コード・打ち消し線，ハッシュタグ |
| `[{text}](https://ja.wikipedia.org/wiki/{text\|url})` | Wikipedia へのリンク |
| `{text\|kansuji}` `{text\|daiji}` `{text\|comma}` | 語の中の数字を漢数字・大字・3 桁区切りに(「12000円」→ 一万二千円，壱万弐千円，12,000円)．数字の無い語では出ない |

以前の版から更新すると，新しく増えた形はオフの状態で一覧の末尾に加わります．自分で消した形は元に戻りません．

設定の画面では，形の欄のすぐ右の「{ }」のボタンか，形の欄で `{` を打つと，[書式のチップ](#単語と変換マクロに書ける書き方)が開きます．チップをクリックするとその書き方が形の欄に入り，形の欄のすぐ下に，試す単語と読みに当てた結果が出ます．一覧の「結果」の列には，各行の形を試す単語と読み(入れていなければ「東京」と「とうきょう」)に当てた結果が出ます．

## 単語と変換マクロに書ける書き方

次の書き方は，変換マクロと，日付や時刻などを入力時の値にするユーザー辞書の単語に使えます．未知の名前は，書いたとおりの文字で入力されます．クリップボードや画面の内容を読む名前や，プログラムを実行する名前はありません．まとまりは設定の画面のチップの切り替えと同じです．例は 2026 年 4 月 1 日(水) 9 時 30 分 15 秒(日本時間)の値です．

### 語

変換マクロだけで使えます．例は「東京」(読み とうきょう)のときの値です．

| 書き方 | 意味 | 例 |
|---|---|---|
| `{text}` | 選んでいる語 | 東京 |
| `{reading}` | 読み | とうきょう |
| `{reading\|katakana}` | 読みのカタカナ | トウキョウ |
| `{reading\|romaji}` | 読みのローマ字 | toukyou |

### 書式

| 記号 | 意味 | 例 |
|---|---|---|
| `YYYY` | 年 | 2026 |
| `YY` | 年(下 2 桁) | 26 |
| `MM` | 月(2 桁) | 04 |
| `M` | 月 | 4 |
| `MMMM` | 英語の月 | April |
| `MMM` | 英語の月(略) | Apr |

| `D` | 日 | 1 |
| `DDDD` | 年の何日目か(3 桁) | 091 |
| `DDD` | 年の何日目か | 91 |
| `dddd` | 曜日 | 水曜日 |
| `ddd` | 曜日(略) | 水 |
| `EEEE` | 英語の曜日 | Wednesday |
| `EEE` | 英語の曜日(略) | Wed |
| `hh` | 時(24 時間制，2 桁) | 09 |
| `h` | 時(24 時間制) | 9 |
| `KK` | 時(12 時間制，2 桁) | 09 |
| `K` | 時(12 時間制) | 9 |
| `A` | 午前・午後 | 午前 |
| `AA` | AM・PM | AM |
| `mm` | 分(2 桁) | 30 |
| `m` | 分 | 30 |
| `ss` | 秒(2 桁) | 15 |
| `s` | 秒 | 15 |

| `E` | 元号の年 | 8 |
| `EE` | 元号の年(1 年は「元」) | 8 |

| `FF` | 年度(下 2 桁) | 26 |
| `NN` | 和風月名 | 卯月 |
| `JJ` | 干支 | 丙午 |
| `WW` | 週番号(2 桁) | 14 |
| `W` | 週番号 | 14 |
| `Q` | 四半期 | 2 |
| `ZZ` | 時間帯 | +09:00 |
| `'Q'` | ' で囲んだ文字はそのまま出力 | Q2 |

日時の名前(`date`・`time`・`datetime`・`utc`・`unixtime`・`holiday`・`season`・`greeting`・`days`・`age`)のあとに，ずらす量(`+1d`・`-30m`)と合わせる先(`@mon`〜`@sun`・`@1`〜`@31`・`@end`)を左から順に書けます．単位は m 分・h 時間・d 日・w 週・M 月・y 年・b 営業日(土日と祝日を除く日)です．1 か月後が月末を超えるときは月末になります．

祝日は 2020〜2099 年の祝日・振替休日・国民の休日です．日数は過ぎた日なら負の数で，年を書かなければ次に来るその日までを数えます．時候の挨拶は 1 月の「厳寒の候」から 12 月の「師走の候」まで，時刻の挨拶は 4〜10 時が「おはようございます」，11〜17 時が「こんにちは」，ほかは「こんばんは」です．

値の変え方は続けて書くと左から順にかかります．数字の変え方(`kansuji` など)は，小数点以下の数字と 17 桁以上の数字には適用しません．`circled` は 0〜50 の数字だけを丸数字にします．書式の記号を 1 文字(`M`・`D`・`h` など)にすると 1 桁の数に 0 を付けません．`'` で囲んだ文字は記号として読みません．

## ローマ字と記号

ローマ字の変換表には，組み合わせを 500 個まで追加できます(「wyi」→「ゐ」)．

記号の変換(「->」→「→」，「やじるし」→「→」)は，既定の組み合わせの変更や無効化と，新しい組み合わせの追加ができます．

## 絵文字と記号

| 項目 | 既定 | 選択肢・説明 |
|---|---|---|
| 絵文字と記号のパレット | オン | Control+Option+E・K・F(Windows は Ctrl+Alt+E・K・F)で絵文字・記号・顔文字のパレットを開く．キーはキー設定で変更できる |
| 入力後にパレットを閉じる | オン | オフにすると，Enter で入力しても閉じない |
| 使用履歴を記録 | オン | よく使う文字の行と検索結果の順に使う．このパソコンの中にだけ保存し，macOS は「使用履歴を消去」で消去できる．ピン留めと肌の色は消去の対象外 |
| パレットの列数 | 9 | 6〜14 |
| パレットの行数 | 6 | 一度に表示する行の数．3〜12 |
| パレットのマスの大きさ | 36 pt | 28〜64 pt |
| よく使う文字の行数 | 1 | 0〜4．0 で表示しない |
| パレットに文字の説明を表示 | オン | パレットの下に，選んでいる文字の名前・読み・ショートコード・コードポイントを表示する |
| 説明に Unicode の名前を表示 | オン | 1 つのコードポイントの文字は Unicode の文字の名前(😄 は「SMILING FACE WITH OPEN MOUTH AND SMILING EYES」)，国旗などの組み合わせの絵文字は CLDR の英語の名前(🇯🇵 は「flag: Japan」)を表示する |
| 説明に読みを表示 | オン | パレットで探すときに使える読みを表示する |

## キー設定

キー操作は，状態・キー・コマンドの組で設定します．標準・Windows 風・Mac 風・ATOK 風・Emacs 風・Vim 風のひな形から始められます．

| 状態 | 意味 |
|---|---|
| いつでも | すべての状態 |
| 未入力 | 何も入力していないとき |
| 入力中 | 読みを入力しているとき |
| 変換中 | 候補を選んでいるとき |
| 英数 | 英数入力のとき |

標準のキーは[使い方](usage.md)にまとめています．

## 除外設定

アプリごとに入力の扱いを決められます．エディタとターミナルは，初めから登録しています．

| 動作 | 内容 |
|---|---|
| IME を使わない | 常に英数で入力する |
| IME オフ | アプリに切り替えるたびに英数にする．あとから日本語入力にも切り替えられる |
| IME オン | アプリに切り替えるたびに日本語入力にする |
| IME のオン・オフを記憶 | そのアプリで最後に使った入力モードに戻す．覚えた入力モードは，ログアウトや再起動で消える |
| 記号は半角 | 記号とスペースを半角で入力する |
| コマンドは英字 | 記号を半角にし，行の先頭のコマンドを英字のまま入力する |

IME オフ・IME オン・IME のオン・オフを記憶は，ほかの動作と組み合わせて同じアプリに登録できます．

## 同期とバックアップ

同期のフォルダに Dropbox・Google Drive・iCloud Drive などのフォルダを指定すると，複数のパソコンで設定と辞書を同期でき，同期する項目も選べます．

| 既定 | 項目 |
|---|---|
| 同期する | 入力・キー設定・変換・補正・記号・ユーザー辞書・インポートした辞書 |
| このパソコンだけ | キー配列・外観・除外設定・統計 |

バックアップでは，すべての設定を JSON で書き出したり読み込んだりできます．
