## 英語と日本語

英字で入力した語を，英語のままにするか日本語にするかを設定します．

| 項目 | 既定 | 説明 |
|---|---|---|
| 前の単語で判別 | オン | 「make」のように両方に読める語を，前の単語に合わせて判別する |
| 不適切な変換を避ける | オン | |
| 常に英語にする単語 | なし | |
| 常に日本語にする単語 | なし | |
| 判別ルール | なし | 語と直前の文脈ごとに，英語と日本語のどちらにするかを指定する |

## ユーザー辞書と辞書の取り込み

ユーザー辞書には 10,000 語まで登録できます．読みはひらがなのほか，ローマ字や英字(「gh」→ GitHub)でも登録できます．Google 日本語入力・Microsoft IME・ATOK の書き出したファイルをそのまま読み込めます．

「単語の {datetime:…} などを入力時の値にする」(既定はオフ)をオンにすると，単語に書いた `{datetime:YYYY/MM/DD hh:mm:ss}`・`{date}`・`{time}`・`{datetime+1d:MM/DD}`・`{uuid}`・`{random:1-6}` を，入力したときの値にします．「にちじ」を変換すると，登録しなくても「2026/11/01 12:34:56」などの日時を出します．

辞書の取り込みでは，数十万語の辞書も使用できます．

| 項目 | 内容 |
|---|---|
| 形式 | 読み・単語・品詞のタブ区切りテキスト，SKK 辞書，macOS のユーザ辞書(plist) |
| 文字コード | UTF-8 / UTF-16 / Shift_JIS / EUC-JP |
| 上限 | 32 個，1 ファイル 256MB |
| 使用する場面 | 常に / 指定したアプリ / 文脈に合わせる |

連想変換の辞書も取り込めます(8 個，1 ファイル 64MB まで)．

## コマンドと変換マクロ

| 項目 | 既定 | 説明 |
|---|---|---|
| 読みでコマンドを呼び出す | オフ | 登録した読みを変換すると，候補の一覧に「▶ 名前」が並ぶ．選んで確定したときだけ，アプリ・Web ページ・ファイルを開く(macOS はショートカットも実行できる)．第 1 候補にはならない |
| コマンド | なし | 読み・名前・動作・行き先．200 個まで．このコンピュータだけに保存し，同期や設定の読み込みでは変わらない |
| 連想変換のキーで変換マクロを表示 | オフ | 変換中に連想変換のキーを押すと，選んでいる語を整えた形(「」で囲む・ルビを付けるなど)を「整形」に並べる |
| 変換マクロ | 9 個 | `{text}` が語，`{reading}` が読み．`{text|upper}` のように変換もかけられる |

## ローマ字と記号

ローマ字の変換表には，組み合わせを 500 個まで追加できます(「wyi」→「ゐ」)．

記号の変換(「->」→「→」，「やじるし」→「→」)は，既定の組み合わせを変更・無効化し，新しく追加できます．

## キー設定

状態・キー・コマンドの組でキー操作を設定します．ひな形は標準・Windows 風・Mac 風・Emacs 風・Vim 風から選べます．

| 状態 | 意味 |
|---|---|
| いつでも | すべての状態 |
| 入力文字なし | 何も入力していないとき |
| 入力中 | 読みを入力しているとき |
| 変換中 | 候補を選んでいるとき |
| 英数 | 英数入力のとき |

標準のキーは [使い方](usage.md) を参照してください．

## 除外設定

アプリごとに動作を変更します．既定でエディタとターミナルを登録しています．

| 動作 | 内容 |
|---|---|
| IME を使わない | 常に英数で入力する |
| 記号を半角 | 記号とスペースを半角で入力する |
| コマンドを英字 | 記号を半角にし，行の先頭のコマンドを英字のまま入力する |

## 外観

| 項目 | 既定 | 選択肢 |
|---|---|---|
| テーマ | 標準 | 標準 / 和紙 / 北欧 / ネオン / 端末 / 高コントラスト / プラチナ / 夜のデスク |
| 候補の文字サイズ | 15 | 12〜24 |

カスタムテーマでは，色・角の丸み・枝の形・書体を変更できます．

## 同期とバックアップ

同期のフォルダに Dropbox・Google Drive・iCloud Drive などのフォルダを指定すると，設定と辞書を複数のパソコンで同期します．項目ごとに同期するかどうかを選べます．

| 既定 | 項目 |
|---|---|
| 同期する | 入力・キー設定・変換・補正・記号・ユーザー辞書・取り込んだ辞書 |
| このパソコンだけ | キー配列・外観・除外設定・統計 |

バックアップでは，すべての設定を JSON で書き出し，読み込めます．
