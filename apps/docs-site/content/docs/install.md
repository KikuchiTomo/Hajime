## macOS

macOS 14 以降に対応しています．

1. [最新のリリース](https://github.com/KikuchiTomo/Hajime/releases/latest)から `.pkg` をダウンロードし，インストールします．
2. 一度ログアウトしてから，ログインし直します．
3. システム設定 > キーボード > 入力ソース で「+」を押し，日本語の「はじめ」を追加します．メニューバーには，日本語の入力中は「はじめ」，英字の入力中は「Hajime」と表示されます．

アップデートは，入力メニューか設定の「情報」にある「更新を確認」から行えます．新しいバージョンがあれば変更点が表示され，「更新する」を押すとダウンロードからインストールまで自動で進みます．途中で管理者のパスワードを求められます．インストールのあと，ログアウトしてログインし直すと新しいバージョンに替わります．新しい `.pkg` を手動でインストールしても構いません．

アンインストールは，入力ソースから「はじめ」と「Hajime」を削除したあと，`/Library/Input Methods/Hajime.app` を削除します．

## Windows

Windows 10 22H2 以降(64 ビット)に対応しています．インストールには管理者の権限が必要です．

1. [最新のリリース](https://github.com/KikuchiTomo/Hajime/releases/latest)から `.msi` をダウンロードし，インストールします．
2. PC を再起動します．
3. 設定 > 時刻と言語 > 言語と地域 で「日本語」の「言語のオプション」を開き，「キーボードの追加」から「Hajime IME」を追加します．

> [!NOTE]
> インストーラーにはまだ署名していないため，SmartScreen の警告が表示されます．「詳細情報」から「実行」を選んでください．

アップデートは，入力メニューか「Hajime IME の設定」の「情報」にある「更新を確認」から行えます．新しいバージョンがあれば変更点が表示され，「更新する」を押すとダウンロードからインストールまで自動で進みます．途中でユーザーアカウント制御の確認が表示されます．インストールのあと，再起動すると新しいバージョンに替わります．新しい `.msi` を手動でインストールしても構いません．

アンインストールは，設定 > アプリ > インストールされているアプリ で「Hajime IME」を選んで行います．

### ゲームの中で日本語を入力できないとき

VALORANT や League of Legends など Riot Vanguard を使うゲームでは，入力モードが「あ」でも英字がそのまま入り，Hajime IME で日本語を入力できないことがあります．Vanguard は信頼できる証明書で署名されていない DLL をゲームに読み込ませず，Hajime IME の DLL にはまだ署名がないためです．

ゲームの中で日本語を入力するときは，Windows キー + Space で Microsoft IME に切り替えてください．
