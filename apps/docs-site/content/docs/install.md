## macOS

macOS 14 以降に対応しています．

1. [最新のリリース](https://github.com/KikuchiTomo/Hajime/releases/latest)から `.pkg` をダウンロードし，インストールします．
2. 一度ログアウトしてから，ログインし直します．
3. システム設定 > キーボード > 入力ソース で「+」を押し，日本語の「Hajime IME」を追加します．

アップデートするときは，入力メニューまたは設定の「情報」の「更新を確認」を押します．新しいバージョンがあれば変更点が表示され，「更新する」を押すとダウンロードからインストールまで自動で実行します．インストールの前に管理者のパスワードの入力を求められます．アップデート後のログアウトは不要で，次の文字入力から新しいバージョンが動作します．新しい `.pkg` を手動でダウンロードしてインストールすることもできます．

アンインストールするときは，入力ソースから「Hajime IME」を削除し，`/Library/Input Methods/Hajime.app` を削除します．

## Windows

Windows 10 22H2 以降(64 ビット)に対応しています．インストールには管理者の権限が必要です．

1. [最新のリリース](https://github.com/KikuchiTomo/Hajime/releases/latest)から `.msi` をダウンロードし，インストールします．
2. 一度サインアウトしてから，サインインし直します．
3. 設定 > 時刻と言語 > 言語と地域 で「日本語」の「言語のオプション」を開き，「キーボードの追加」から「Hajime IME」を追加します．

> [!NOTE]
> インストーラーにはまだ署名していないため，SmartScreen の警告が表示されます．「詳細情報」から「実行」を選んでください．

アップデートするときは，「Hajime IME の設定」の「情報」で「更新を確認」を押します．新しいバージョンがあれば変更点が表示され，「更新する」を押すとダウンロードからインストールまで自動で実行します．インストールの前にユーザーアカウント制御の確認が表示されます．新しい `.msi` を手動でダウンロードしてインストールすることもできます．

アンインストールするときは，設定 > アプリ > インストールされているアプリ から「Hajime IME」をアンインストールします．

### ゲームの中で日本語を入力できないとき

VALORANT や League of Legends など，Riot Vanguard を使うゲームでは，ゲームの中で「Hajime IME」を使えないことがあります．Vanguard は信頼できる証明書で署名されていない DLL をゲームに読み込ませず，「Hajime IME」の DLL にはまだ署名していないためです．このとき，入力モードが「あ」のままでも英字がそのまま入ります．

ゲームの中で日本語を入力するときは，Windows キー + Space で Microsoft IME に切り替えてください．
