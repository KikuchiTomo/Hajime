## macOS

macOS 14 以降に対応しています．

1. [最新のリリース](https://github.com/KikuchiTomo/Hajime/releases/latest)から `.pkg` をダウンロードし，インストールします．
2. ログアウトして，再度ログインします．
3. システム設定 > キーボード > 入力ソース の「編集…」で「+」を押し，言語の一覧から「日本語」を選択して「はじめ」を追加します．

入力ソースの一覧とメニューバーでは，Hajime IME は次の名前で表示されます．

| 表示 | 入力モード |
|---|---|
| はじめ | Hajime IME の日本語入力 |
| Hajime | Hajime IME の英字入力 |

### アップデート {#macos-update}

1. 入力メニューか設定の「情報」にある「更新を確認」を選択します．
2. 表示された変更点を確認して「更新する」を押すと，ダウンロードからインストールまで自動で実行されます．途中で管理者パスワードの入力が必要です．
3. ログアウトして再度ログインすると，新しいバージョンに切り替わります．

新しい `.pkg` による手動でのアップデートも可能です．

### アンインストール {#macos-uninstall}

入力ソースから「はじめ」と「Hajime」を削除後，`/Library/Input Methods/Hajime.app` を削除します．

## Windows

Windows 10 22H2 以降(64 ビット)に対応しています．インストールには管理者権限が必要です．

1. [最新のリリース](https://github.com/KikuchiTomo/Hajime/releases/latest)から `.msi` をダウンロードし，インストールします．
2. PC を再起動します．
3. 設定 > 時刻と言語 > 言語と地域 で「日本語」の「言語のオプション」を開き，「キーボードの追加」から「Hajime IME」を追加します．

> [!NOTE]
> インストーラーは未署名のため，SmartScreen の警告が表示されます．「詳細情報」から「実行」を選択してください．署名の方針は[コード署名ポリシー](../code-signing-policy.md)をご覧ください．

### アップデート {#windows-update}

1. 入力メニューか「Hajime IME の設定」の「情報」にある「更新を確認」を選択します．
2. 表示された変更点を確認して「更新する」を押すと，ダウンロードからインストールまで自動で実行されます．途中でユーザーアカウント制御の確認が表示されます．
3. PC を再起動すると，新しいバージョンに切り替わります．

新しい `.msi` による手動でのアップデートも可能です．

### アンインストール {#windows-uninstall}

設定 > アプリ > インストールされているアプリ で「Hajime IME」を選択して実行します．

### ゲーム内で日本語を入力できない場合 {#ゲームの中で日本語を入力できないとき}

VALORANT や League of Legends など Riot Vanguard を使用するゲームでは，入力モードが「あ」でも英字がそのまま入力され，Hajime IME で日本語を入力できない場合があります．Vanguard は信頼された証明書で署名されていない DLL の読み込みを禁止しており，Hajime IME の DLL が未署名であることが原因です．

ゲーム内で日本語を入力する場合は，Windows キー + Space で Microsoft IME に切り替えてください．
