---

キーは標準の設定のもので，どのキーも設定の「キー設定」で変更できます．

## 変換と確定

ライブ変換がオンのときは，打つそばから漢字に変換され，Enter で確定できます．Space を押すと，文節ごとに候補が枝分かれした分岐図が表示されます．

| キー | 操作 |
|---|---|
| Space / ↓ | 次の候補 |
| Shift+Space / ↑ | 前の候補(分岐図では上にひらがなとカタカナがあります) |
| ← → | 文節の移動 |
| Tab / Shift+Tab | 文節の移動(端まで行くと反対の端に戻ります) |
| Option+← → | 誤変換の可能性が高い文節へ移動 |
| Home / End | 先頭・末尾の文節へ移動 |
| PageDown / PageUp | 候補の次・前のページ |
| 数字キー | 番号の候補を選択 |
| Enter | 確定 |
| Esc | 直前の候補や区切りの変更を取り消す．続けて押すと全文を読みに戻す |
| Backspace | 全文を読みに戻す |
| Delete | 全文を読みに戻し，末尾から入力を続ける |
| F6〜F8 | 選んでいる文節をひらがな・全角カタカナ・半角カタカナに変換 |
| F9 / F10 | 全文を全角英数・半角英数に変換．続けて押すと大文字・小文字・先頭だけ大文字に変換 |
| Control+Backspace | 選んでいる候補を学習から削除 |
| Option+↓ | 候補を表に広げる(ひな形が Windows 風・Mac 風・ATOK 風なら Tab) |

Esc で取り消せるのは 8 回までで，Space で候補を送り続けた操作や，同じ字種のキーを続けて押した操作はまとめて 1 回と数えます．

Backspace で読みに戻した文は，ライブ変換がオンでも読みを変えるまでかなのまま表示され，Enter でそのまま確定できます．Delete で戻したときは，入力中と同じ表示になります．

### 候補を表に広げる

変換中に Option+↓(Windows は Alt+↓)を押すと，選んでいる文節の候補が 9 行 × 4 列の表に広がり，36 個を一度に見渡せるので，「こう」「しょう」のように候補の多い読みで探しやすくなります．キー設定のひな形が Windows 風・Mac 風・ATOK 風なら，このキーは Tab です．

| キー | 表での操作 |
|---|---|
| ↓ ↑ / Space | 下・上の候補 |
| ← → / Tab | 隣の列の同じ行へ移動．端の列からは次・前のページへ |
| PageDown / PageUp | 次・前のページ(36 個ずつ) |
| 数字キー | 選んでいる列の中の番号の候補を選択 |
| Option+↓ / Esc | 元の表示に戻す(選んだ候補はそのまま) |

番号は選んでいる列にだけ付きます．分岐図から広げた表で数字キーかマウスで候補を選ぶと，表が閉じて次の文節へ進みます．表の行数は設定の「一覧の候補数」で，列数は「表の列数」で変更できます．「候補を送り続けたら表に広げる」をオンにすると，Space や ↓ で最初のページを越えたときに自動で表に広がります．

### 確定の取り消し

確定した直後に Control+Backspace を押すと，入力した文字が消えて変換中の状態に戻り，その学習も取り消されます．文節の区切りや選んだ候補は確定前のままなので，間違えた文節だけを選び直せます．Esc で確定前の変更をさかのぼって取り消すこともできます．ライブ変換の文や読みをそのまま確定したときは，入力中の状態に戻ります．

確定した直後なら，再変換のキー(変換キー)でも同じように戻せます．ほかのキーを押したり，カーソルを動かしたりしたあとは取り消せず，Control+Backspace はそのままアプリに渡ります．キーはキー設定の「確定を取り消し」で変更できます．

設定の「テンキーの Enter で計算」をオンにすると，テンキーで「12*3」と打って Enter を押したときに，計算結果の 36 が第 1 候補になります．

## 入力中の候補と予測

設定の「入力中の候補」で表示を選ぶと，入力中に変換の候補が小さな窓に表示されます．↓ で候補を，↑ で文字種を選び始め，そのあとは数字キーでも選べます．それまでの数字キーは，そのまま数字として入力されます．候補が「入力中の候補を表示しない件数」以下なら窓は出ず，↓ で通常の変換が始まります．

設定の「入力中の予測」で表示を選ぶと，「えぴ」と打てば「エピソード」のように，続きを予測した語句が入力位置のすぐ右に表示されます．予測で補う部分は薄い色で表示され，Tab で確定できます．予測が出ていないときに Tab を押すと，入力中の候補を選び始めます．Tab の代わりのキーは，キー設定の「「もしかして」に修正・予測を確定」で変更できます．

予測には以前に確定した語句が優先して並び，設定の「入力履歴にある予測を優先」をオフにすると辞書の順になります．打ち間違いを補正した読みや「もしかして」の読みからも予測しますが，「もしかして」が出ている間の Tab は読みの修正になり，修正したあとにもう一度 Tab を押すと予測を確定します．補正した読みから予測しないようにするには，設定の「打ち間違いを直した読みからも予測」をオフにします．

出てほしくない予測は，表示中に Control+Backspace を押すと「予測に表示しない語句」に登録され，次の予測に替わります．キー設定のひな形が Windows 風・Mac 風・ATOK 風なら，このキーは Control+Delete です．登録は設定の「変換」の「予測に表示しない語句」で解除でき，キーはキー設定の「予測に表示しない」で変更できます．

Tab で予測を確定した直後に Backspace を押すと，補う前の「えぴ」に戻り，学習も取り消されます(ひな形が Windows 風・ATOK 風なら Control+Backspace)．取り消した予測は，同じ読みを打っている間はもう出ません．ほかのキーを押したりカーソルを動かしたりしたあとの Backspace は，ふつうの 1 文字削除です．キーはキー設定の「予測の確定を取り消し」で変更できます．

## 文節の操作

| キー | 操作 |
|---|---|
| Shift+← → | 文節を 1 文字短く・長く |
| Shift+Control+← → | 文節を単語の切れ目まで短く・長く |
| Shift+↓ | 文節の単語の切れ目に番号を表示し，数字キーで分割 |
| Shift+Backspace | 選んでいる文節を消して，その場で入力し直す |
| Option+Space | 入力中に，その位置を文節の区切りにする |

文節を入力し直す間も分岐図は表示されたままで，文節を移動するか Space か Enter を押すと新しい読みで変換されます．Esc を押すと元の文節に戻ります．

## 打ち間違いの補正

入力を止めると，文脈から打ち間違いを見つけて補正し，その部分に点線の下線を引きます．Esc を押すと入力どおりに戻ります．判断がつかないときは「もしかして」で候補を示すだけにとどめ，Tab でその候補に修正します．ローマ字で打った英単語のつづり(「pthon」→「python」)も補正の対象です．

補正してほしくない語句は，設定の「補正」で登録できます．

## 語の意味

変換中に選んでいる語の意味を収録していれば，品詞・意味・使い方の例・同音語が候補の窓の横の吹き出しに表示されます．吹き出しの三角は選んでいる候補を指します．意味が 2 つ以上ある語には番号が付きます．

表示する位置(吹き出しか候補の下)や意味の数，品詞・使い方の例・同音語を出すかどうかは，設定の「変換」の「語の意味」で変更できます．

## 連想変換

入力中は Shift+Space，変換中は Shift+↑ を押すと，選んでいる語と似た意味の語や関連する語が表示されます．↑↓ で語を，← → で意味を選び，Enter で確定します．

設定の「コマンド」で変換マクロをオンにすると，同じキーで【東京】や東京（とうきょう），|東京《とうきょう》，toukyou のように語を整えた形も「整形」に並びます．形は日付や乱数も使って自由に追加でき，設定の画面で試せます．書き方は[単語と変換マクロに書ける書き方](settings.md#単語と変換マクロに書ける書き方)を参照してください．

## 便利な変換

| 入力 | 候補 |
|---|---|
| 1+2*3= | 7，1+2*3=7 |
| 100-0001 | 東京都千代田区千代田 |
| 21 | ㉑，二一，弐拾壱，ⅩⅩⅠ |
| 2026 | 二〇二六，弐千弐拾六，ⅯⅯⅩⅩⅥ |
| きょう・あした・いま | 2026/10/30，10月30日(金) など |
| なう | なう (2026/10/30 12:34) |
| やじるし | → ← ↑ ↓ |
| -> | → |
| ねこ・わらう・びーる | 🐈 😺，😀 😁，🍺 🍻(Space で変換したとき) |
| ねこが・びーるを | 🐈が，🍺を(Space で変換したとき) |

数字のあとの「.」「,」はピリオドとカンマに，英数字のあとの「-」はハイフンになるので，「3.14」「1,000」「A-1」を英数に切り替えずに入力できます．読みの先頭で数字の前に置いた「-」も，「-3」のようにハイフンになります．

絵文字は，Space などで変換したときの候補(分岐図と一覧)に，4 番目から 2 つ表示します．入力中は表示しません．ライブ変換の文字と入力中の候補の窓が絵文字に変わることはありません．

- 文節の読みが絵文字の読みと同じとき(「びーる」)は，文節全体を絵文字にした候補(🍺)を表示します
- 文節が絵文字にできる語と助詞などでできているとき(「ねこが」)は，語の部分を絵文字にした候補(🐈が)を表示します．文の途中の文節でも同じです
- 1 文字の読み(「は」「き」)には表示しません．助詞や語の一部と区別できないためです
- 肌の色を変えられる絵文字は，パレットで選んだ肌の色で表示します．macOS と Windows が表示できない新しい絵文字は出しません
- 選んだ絵文字は，次からその読みの絵文字の先頭に表示します．記録はパレットで使った文字と同じ場所に保存します
- 絵文字の候補の横に，絵文字の名前(😄 なら「笑顔」)を小さく表示します．表示しないようにもできます

2 つの表示は，設定の「変換」の「文節を絵文字に変換」と「語を絵文字に変換」で別々にオン・オフできます．表示する位置と数は「絵文字の位置」「絵文字の数」で変更でき，2 つに共通です．

## 再変換

確定した文字を選んで Control+Shift+R(または変換キー)を押すと，読みに戻して変換し直せます．確定した直後なら，文字を選ばなくても確定前の変換に戻ります．

## 手書き入力

設定の「変換」で手書き入力をオンにすると，Control+Option+H(Windows は Ctrl+Alt+H)で手書きの画面が開き，書いた文字を候補から選んで入力できます．

## 絵文字と記号のパレット

Control+Option+E で絵文字，Control+Option+K で記号，Control+Option+F で顔文字のパレットが開きます．Windows では Control+Option の代わりに Ctrl+Alt を使います．入力メニューの「絵文字と記号」からも開け，開いている間に打った文字はパレットの検索欄に入ります．

- 読み(おじぎ)・名前・英語(bow)・ショートコード(:bow:)で探せます．ローマ字の「ojigi」や「neko」はかなとして探し，英語は「tmbsup」で 👍 が出るように途中の文字が抜けていても見つかります
- 「:bow:」のようにコロンで閉じたショートコードを打つと，その絵文字がすぐに入力されます．ローマ字入力なら，パレットを開かずに「:bow:」と続けて打っても絵文字になります
- 記号は「やじるし」「こめじるし」「まるいち」「せっし」など，変換と同じ読みで探せます
- 顔文字は「にこにこ」「しょぼーん」などの読みで，顔文字のパレットから探せます．絵文字や記号の検索結果には出ません
- 一覧の上には，ピン留めした文字とよく使う文字が並びます．よく使う文字の順は開くたびに更新され，開いている間は動きません
- 同じ語で何度も選んだ文字は，次にその語で探すと先頭に出ます

パレットの下には，選んでいる文字の日本語の名前と，Unicode の名前・読み・ショートコード・コードポイントが表示されます．日本語の名前は Unicode CLDR(Common Locale Data Repository)のもので，一部の記号には Hajime IME が名前を付けています．どちらの名前かは，名前の右の「CLDR」「Hajime IME」でわかります．国旗のように複数の文字を組み合わせた絵文字には Unicode の名前が無いので，代わりに CLDR の英語の名前を表示します．表示する項目は設定の「絵文字と記号」で選べます．

| キー | 動作 |
|---|---|
| 矢印 | 文字を選ぶ |
| Tab / Shift+Tab | 次の分類 / 分類の先頭か前の分類 |
| Control+Tab | 絵文字・記号・顔文字を順に切り替える |
| Enter | 選んでいる文字を入力して閉じる |
| Shift+Enter | 入力して閉じずに続ける |
| Option+Enter(Windows は Alt+Enter) | 肌の色を選ぶ．選んだ色は次からもその絵文字に使う |
| Control+D | ピン留めする・外す |
| Esc | 検索の語を消す．もう一度押すと閉じる |

マウスでも操作でき，既定の肌の色はパレットの右下のボタンで変更できます．使った文字の記録はこのパソコンの中にだけ保存し，外部には送信しません．パレットの大きさや，入力したあとに閉じるかどうかは，設定の「絵文字と記号」で変更できます．

パレットを開くときや選択を動かすときのアニメーションは，OS の設定で止められます．macOS はシステム設定の「アクセシビリティ」→「ディスプレイ」→「視差効果を減らす」をオンに，Windows は設定の「アクセシビリティ」→「視覚効果」→「アニメーション効果」をオフにしてください．

## 設定を開く

設定画面は，入力メニューの「設定を開く…」か，Control+Option+カンマ(Windows は Ctrl+Alt+カンマ)で開きます．

> [!NOTE]
> cmux など一部のアプリでは，入力メニューの項目が動かないことがあります(修正中です)．そのときはキーで設定画面を開いてください．
