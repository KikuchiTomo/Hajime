記載のキーは標準設定のもので，すべて設定の「キー設定」で変更可能です．Windows では Option の代わりに Alt を使用します．

## 変換と確定

{{< hajime/figure src="images/features/live-conversion.webp" alt="ローマ字の入力が，Space を押さずに「帰りに駅前のカフェに寄って」と変換されている" >}}

ライブ変換がオンの場合は入力と同時に変換され，Enter で確定します．Space を押すと，文節ごとの変換候補がツリー表示されます．

| キー | 操作 |
|---|---|
| Space / ↓ | 次の候補 |
| Shift+Space / ↑ | 前の候補 |
| ← → | 文節の移動(ツリー表示では[ツリー表示の操作](#ツリー表示の操作)のとおり) |
| Tab / Shift+Tab | 文節の移動(端からは反対の端へ移動) |
| Option+← → | 誤変換の可能性が高い文節へ移動 |
| Home / End | 先頭・末尾の文節へ移動 |
| Option+A・S・D・F・J・K・L・; | 1〜8 番目の文節へ移動 |
| PageDown / PageUp | 候補の次・前のページ |
| 数字キー | 番号の候補を選択 |
| Enter | 確定 |
| Esc | 直前の候補・区切りの変更を取り消し．連続で押すと全文を読みに戻す |
| Backspace | 全文を読みに戻す |
| Delete | 全文を読みに戻し，末尾から入力を継続 |
| F6〜F8 | 選択中の文節をひらがな・全角カタカナ・半角カタカナに変換 |
| F9 / F10 | 全文を全角英数・半角英数に変換．連続で押すと大文字・小文字・先頭のみ大文字に切り替え |
| Control+Backspace | 選択中の候補を学習から削除 |
| Option+↓ | [候補を一覧表示](#候補を表に展開) |

- 1〜8 番目の文節への移動は，キー設定のプリセットが Mac 風の場合 Shift+Option+A・S・D・F・G・H・J・K です．長い文では表示中の範囲内で数え，対応するキーは Option を押している間，ツリー表示の文節の下に表示されます．
- Option+↓ は，プリセットが Windows 風・Mac 風・ATOK 風の場合 Tab です．
- Esc による取り消しは 8 回まで可能です．Space の連続入力による候補の移動と，F9・F10 など同じキーの連続入力は，1 回として扱います．
- Backspace で読みに戻した文は，読みを編集するまでかなのまま表示され(ライブ変換がオンの場合も同様)，Enter でそのまま確定可能です．Delete で戻した場合は，入力中と同じ表示になります．

### ツリー表示の操作

{{< hajime/figure src="images/features/candidate-tree.webp" alt="「私の名前は中野です」のツリー表示．文節の上に文字種，下に候補が表示されている" >}}

ツリー表示は矢印キーのみで操作可能で，表示上の位置関係のとおりに移動します．変換直後は文節が選択された状態のため，← → でそのまま文節を移動可能です(設定の「変換の直後に文節を選択」で変更可能)．

| 現在位置 | ↑ | ↓ | ← → |
|---|---|---|---|
| 文節 | 文字種へ | 候補へ | 前・次の文節 |
| 文字種(ひらがな・カタカナなど) | ― | 文節へ戻る | 前・次の文字種 |
| 候補 | 前の候補(先頭の場合は文節へ) | 次の候補 | 意味・連想・マクロが表示されている側はその項目へ，反対側は選択した候補のまま文節へ戻る |
| 意味・連想・マクロ | 候補へ戻る | 内容へ移動 | 前・次の項目(最初の項目から戻る方向は候補へ) |
| 意味・連想・マクロの内容(連想の単語・マクロの結果) | 前の単語(先頭の場合は項目へ戻る) | 次の単語 | 前・次の意味(最初の意味から戻る方向は，選択した単語のまま文節へ戻る) |

- 意味・連想・マクロは，通常は候補の右側に表示されます．画面の端などで右側に表示できない場合は左側に表示され，← で移動します．
- 連想の単語とマクロの結果は，Enter か数字キーで文節に反映されます．この時点では全文は確定されないため，続けてほかの文節を変換可能です．全文の確定には，もう一度 Enter を押します．
- 長い文は 8 文節ごとに分割して表示されます．前後に続きがある場合は線の端に記号が表示され，文節の移動に合わせて表示範囲が切り替わります．一度に表示する文節数は，設定の「分岐図に一度に表示する文節数」で変更可能です．
- 矢印キーによる上記の操作は，キー設定のプリセットが標準の場合に有効です．ほかのプリセットでは ← → が文節の移動に固定されており，キー設定の「候補の先の枝へ移動」にキーを割り当てることで同じ操作が可能です．

### 候補の一覧表示 {#候補を表に展開}

{{< hajime/figure src="images/catalog/grid.webp" alt="1 つの文節の候補が 4 列の表で一覧表示されている" >}}

変換中に Option+↓ を押すことで，選択中の文節の候補 36 個を 9 行 × 4 列の表で一覧表示可能です．「こう」「しょう」のように候補の多い読みに有効です．

| キー | 操作 |
|---|---|
| ↓ ↑ / Space | 下・上の候補 |
| ← → / Tab | 隣の列の同じ行へ移動．端の列からは次・前のページへ移動 |
| PageDown / PageUp | 次・前のページ(36 個単位) |
| 数字キー | 選択中の列の番号の候補を選択 |
| Option+↓ / Esc | 元の表示に戻る(選択した候補は維持) |

- 番号は選択中の列にのみ表示されます．
- ツリー表示から開いた表では，数字キーかマウスで候補を選択すると，表が閉じて次の文節へ移動します．
- 行数は設定の「一覧の候補数」，列数は「表の列数」で変更可能です．
- 設定の「ページ送りで表に展開」をオンにすることで，Space や ↓ で最初のページを越えた際に，自動で表に切り替え可能です．

### 確定取り消し {#確定の取り消し}

{{< hajime/figure src="images/catalog/undo-commit.webp" alt="確定した「今日は雷」が，Control+Backspace で変換中の状態に戻っている" >}}

確定直後に Control+Backspace を押すことで，確定前の変換中の状態に復帰可能です．確定時の学習も取り消されます．

- 文節の区切りと選択した候補は確定前の状態で復元されるため，誤った文節のみ再選択可能です．Esc により，確定前の変更をさかのぼって取り消すことも可能です．
- ライブ変換の結果や読みをそのまま確定した場合は，入力中の状態に復帰します．
- 確定直後であれば，再変換のキー(変換キー)でも同様に復帰可能です．
- ほかのキーの入力やカーソルの移動のあとは取り消し不可で，Control+Backspace はそのままアプリに送信されます．
- キーはキー設定の「確定を取り消し」で変更可能です．

## 入力中の候補と予測

{{< hajime/figure src="images/features/suggestion-prediction.webp" alt="入力中の候補「なんだ」「何だ」と，Tab で確定する予測「エピソード」" >}}

入力中に，変換候補と続きの予測を表示する機能です．設定の「変換」の「入力中の候補」「入力中の予測」で，それぞれ有効化可能です．

### 入力中の候補

入力中の読みに対する変換候補を，小さなウィンドウに表示します．

| キー | 操作 |
|---|---|
| ↓ | 候補の選択を開始 |
| ↑ | 文字種の選択を開始 |
| 数字キー | 選択の開始後は番号の候補を選択(開始前は数字を入力) |

候補数が設定の「入力中の候補を省略する件数」以下の場合はウィンドウを表示せず，↓ で通常の変換を開始します．

### 予測

「えぴ」に対する「エピソード」のように，続きを予測した語句を入力位置の右に薄い色で表示します．

| 操作 | キー | プリセットによる違い | キー設定の項目 |
|---|---|---|---|
| 予測を選択 | Tab | ― | 「もしかして」に修正・予測を確定 |
| 選択した予測を取り消し | 選択直後に Backspace | 確定した予測の取り消しは，Windows 風・ATOK 風では Control+Backspace | 予測の確定を取り消し |
| 表示中の予測を除外 | Control+Backspace | Windows 風・Mac 風・ATOK 風は Control+Delete | 予測から除外 |

- Tab で選択した予測は未確定のまま表示され，続けて入力・Space での変換・Enter での確定が可能です．設定の「予測の選択後も入力を継続」をオフにすることで，Tab で確定する動作に変更可能です．
- 予測が表示されていない状態で Tab を押すと，入力中の候補の選択を開始します．
- 選択直後の Backspace で，補完前の読み(「えぴ」)に復帰します．Tab で確定する設定では，確定直後の Backspace で同様に復帰し，学習も取り消されます．取り消した予測は，同じ読みの入力中は再表示されません．
- 設定の「入力中の予測」を「入力中のタイミングで制御」にすることで，入力中は予測を表示せず，キー入力が「予測までの待ち時間」だけ止まった時点で表示します．
- 除外した予測は「予測に表示しない語句」に登録され，次の予測に切り替わります．登録は設定の「変換」で解除可能です．
- 予測は確定履歴のある語句を優先して表示します．設定の「入力履歴の予測を優先」をオフにすることで，辞書順に変更可能です．
- 打ち間違いを補正した読みと「もしかして」の読みも予測の対象です．設定の「タイプミス修正後の読みからも予測」をオフにすることで，対象から除外可能です．
- 「もしかして」の表示中は Tab が読みの修正になり，修正後にもう一度 Tab を押すと予測を選択します．

## 文節の操作

{{< hajime/figure src="images/catalog/segments.webp" alt="文節「問題がある」の単語の区切りに番号が表示されている" >}}

| キー | 操作 |
|---|---|
| Shift+← → | 文節を 1 文字単位で伸縮 |
| Shift+Control+← → | 文節を単語単位で伸縮 |
| Shift+↓ | 文節内の単語の区切りに番号を表示し，数字キーで分割 |
| Shift+Backspace | 選択中の文節を削除して再入力 |
| Option+Space | 入力中の位置を文節の区切りに指定 |

文節の再入力中もツリー表示は維持され，文節の移動か Space・Enter で新しい読みを変換します．Esc で元の文節に戻ります．再入力中に英数キーやかなキーを押すと，再入力中の文字のみ英字・かなに切り替わります．

## 打ち間違い補正 {#打ち間違いの補正}

{{< hajime/figure src="images/features/typo-correction.webp" alt="「ありがぷございます」が「ありがとうございます」に補正され，Esc で復元可能" >}}

入力が止まると，文脈から打ち間違いを検出して自動で補正します．補正箇所は点線の下線で表示されます．

| キー | 操作 |
|---|---|
| Esc | 補正を取り消し，入力どおりに復元 |
| Tab | 「もしかして」の候補に修正 |

- 確度が低い場合は自動で補正せず，「もしかして」として候補を提示します．
- ローマ字入力中の英単語のスペルミス(「pthon」→「python」)も補正の対象です．
- 補正の対象外にする語句は，設定の「補正」で登録可能です．

## 意味の表示 {#語の意味}

{{< hajime/figure src="images/features/meaning.webp" alt="「撮る」の意味と用例，同音語の取る・採る・執る・捕る" >}}

変換中は，選択中の単語の品詞・意味・用例・同音語が候補ウィンドウの横に表示されます(意味を収録している単語が対象)．複数の意味を持つ単語には番号が付きます．

表示位置(吹き出し・候補の下)，意味の数，品詞・用例・同音語の表示の有無は，設定の「変換」の「語の意味」で変更可能です．

## 連想変換

{{< hajime/figure src="images/features/association.webp" alt="「撮る」の連想として，撮影する・写す・収めるが表示されている" >}}

選択中の単語の類義語と関連語を表示し，候補として選択可能です．

| 操作 | キー |
|---|---|
| 連想変換を開始 | 入力中は Shift+Space，変換中は Shift+↑ |
| 単語を選択 | ↑ ↓ |
| 意味を切り替え | ← → |
| 選択した単語を反映 | Enter |

ツリー表示では，Enter で選択した単語が文節に反映され，もう一度 Enter を押すと全文を確定します．一覧表示では，Enter でそのまま確定します．

設定の「コマンド」で変換マクロをオンにすることで，同じキーで【東京】，東京（とうきょう），|東京《とうきょう》，toukyou のように単語を整形した結果も「整形」に表示可能です．マクロは日付や乱数も利用して自由に追加可能で，結果は設定画面で確認可能です．書式は[単語と変換マクロの書式](settings.md#単語と変換マクロに書ける書き方)を参照してください．

## 便利な変換

{{< hajime/figure src="images/features/date-conversion.webp" alt="1+2*3= が 7 に，100-0001 が東京都千代田区千代田に，きょうが日付に，21 が ㉑ や二一に変換されている" >}}

| 入力 | 候補 |
|---|---|
| 1+2*3= | 7，1+2*3=7 |
| 100-0001 | 東京都千代田区千代田 |
| 21 | ㉑，二一，弐拾壱，ⅩⅩⅠ |
| 2026 | 二〇二六，弐千弐拾六，ⅯⅯⅩⅩⅥ |
| きょう・あした・いま | 2026/10/30，10月30日(金) など |
| なう | なう (2026/10/30 12:34) |
| やじるし | → ← ↑ ↓ |
| -> | → |
| ねこ・わらう・びーる | 🐈 😺，😀 😁，🍺 🍻(Space での変換時) |
| ねこが・びーるを | 🐈が，🍺を(Space での変換時) |

- 数字の直後の「.」「,」はピリオドとカンマ，英数字の直後の「-」はハイフンになるため，「3.14」「1,000」「A-1」を英数に切り替えずに入力可能です．読みの先頭で数字の前に入力した「-」も，「-3」のようにハイフンになります．
- 設定の「テンキーの Enter で計算」をオンにすることで，テンキーで「12*3」と入力して Enter を押した際に，計算結果の 36 を第 1 候補に表示可能です．

### 絵文字への変換

絵文字は，Space などで変換した際の候補(ツリー表示・一覧表示)の 4 番目から 2 個表示されます．ライブ変換の結果と入力中の候補には表示されません．

| 対象 | 例 | 設定の項目 |
|---|---|---|
| 読みが絵文字の読みと一致する文節 | 「びーる」→ 🍺 | 文節を絵文字に変換 |
| 絵文字に対応する単語と助詞などで構成される文節 | 「ねこが」→ 🐈が | 単語を絵文字に変換 |

- 表示位置と個数は，設定の「絵文字の位置」「絵文字の数」で変更可能です(上の 2 項目に共通)．
- 1 文字の読み(「は」「き」)は，助詞や単語の一部と区別できないため対象外です．
- 肌の色を変更可能な絵文字は，パレットで選択した肌の色で表示されます．OS が未対応の新しい絵文字は表示されません．
- 選択した絵文字は，次回からその読みの絵文字の先頭に表示されます．履歴はパレットの使用履歴と同じ場所に保存されます．
- 絵文字の候補の横には，絵文字の名前(😄 なら「笑顔」)が表示されます．設定の「絵文字の名前を表示」で非表示に変更可能です．

## 再変換

{{< hajime/figure src="images/catalog/reconvert.webp" alt="確定した「貴社」を選択し，Control+Shift+R で「記者」に再変換している" >}}

確定した文字を選択して Control+Shift+R(または変換キー)を押すことで，読みに戻して再変換可能です．確定直後であれば，文字を選択しなくても確定前の変換に復帰します．

## 手書き入力

{{< hajime/figure src="images/features/handwriting.webp" alt="手書きの「田」から候補が表示されている" >}}

設定の「変換」で手書き入力をオンにすることで，Control+Option+H(Windows は Ctrl+Alt+H)で手書き入力の画面を起動可能です．手書きした文字の候補から選択して入力します．

## 絵文字と記号のパレット

{{< hajime/figure src="images/features/palette.webp" alt="顔文字・絵文字・記号のパレットと，それぞれを起動するキー" >}}

| パレット | キー(Windows は Ctrl+Alt) |
|---|---|
| 絵文字 | Control+Option+E |
| 記号 | Control+Option+K |
| 顔文字 | Control+Option+F |

入力メニューの「絵文字と記号」からも起動可能です．表示中に入力した文字は，パレットの検索欄に入力されます．

| 検索方法 | 例 |
|---|---|
| 読み | おじぎ，やじるし，こめじるし，まるいち，せっし |
| 英語(途中の文字が抜けていても検索可能) | bow，tmbsup → 👍 |
| ローマ字(かなとして検索) | ojigi，neko |
| ショートコード | :bow: |
| 顔文字の読み(顔文字のパレットのみ) | にこにこ，しょぼーん |

- 「:bow:」のようにコロンで閉じたショートコードを入力すると，その絵文字が即座に入力されます．ローマ字入力では，パレットを開かずに「:bow:」と入力することでも絵文字に変換可能です．
- 一覧の上部には，ピン留めした文字とよく使う文字が表示されます．よく使う文字の順序は，パレットを開くたびに更新されます．
- 同じ検索語で繰り返し選択した文字は，次回の検索で先頭に表示されます．

| キー | 操作 |
|---|---|
| 矢印 | 文字を選択 |
| Tab / Shift+Tab | 次の分類 / 分類の先頭か前の分類 |
| Control+Tab | 絵文字・記号・顔文字を順に切り替え |
| Enter | 選択中の文字を入力して閉じる |
| Shift+Enter | 閉じずに入力 |
| Option+Enter | 肌の色を選択(選択した色はその絵文字に次回以降も適用) |
| Control+D | ピン留め・解除 |
| Esc | 検索語を消去．もう一度押すと閉じる |

マウスでも操作可能で，既定の肌の色はパレット右下のボタンで変更可能です．

パレットの下部には，選択中の文字の日本語名と，Unicode 名・読み・ショートコード・コードポイントが表示されます．

- 日本語名は Unicode CLDR(Common Locale Data Repository)に基づき，一部の記号には Hajime IME 独自の名前を付けています．名前の出典は，名前の右の「CLDR」「Hajime IME」で確認可能です．
- 国旗のように複数の文字を組み合わせた絵文字には Unicode 名が存在しないため，CLDR の英語名を表示します．
- 表示項目，パレットのサイズ，入力後に閉じるかどうかは，設定の「絵文字と記号」で変更可能です．
- 使用履歴は端末内にのみ保存され，外部には送信されません．

パレットの表示と選択の移動のアニメーションは，OS の設定で無効化可能です．macOS はシステム設定の「アクセシビリティ」→「ディスプレイ」→「視差効果を減らす」をオンに，Windows は設定の「アクセシビリティ」→「視覚効果」→「アニメーション効果」をオフにしてください．

## 設定を開く

設定画面は，入力メニューの「設定を開く…」か，Control+Option+カンマ(Windows は Ctrl+Alt+カンマ)で起動可能です．

> [!NOTE]
> cmux など一部のアプリでは，入力メニューの項目が動作しない場合があります(修正中です)．その場合はキーで設定画面を開いてください．
