---

キーは標準の設定の場合です．すべてのキーは設定の「キー設定」で変更できます．

## 変換と確定

ライブ変換がオンのときは，入力しながら漢字に変換します．Enter で確定します．

Space を押すと候補を表示します．候補は分岐図で表示し，文節ごとに候補が枝分かれします．

| キー | 操作 |
|---|---|
| Space / ↓ | 次の候補 |
| Shift+Space / ↑ | 前の候補(分岐図では上にひらがな・カタカナの候補があります) |
| ← → | 文節の移動 |
| Tab / Shift+Tab | 文節の移動(端の文節からは反対の端の文節へ移ります) |
| Option+← → | 誤変換の可能性が高い文節へ移動 |
| Home / End | 先頭・末尾の文節へ移動 |
| PageDown / PageUp | 文節の候補の次・前のページ |
| 数字キー | 番号の候補を選択 |
| Enter | 確定 |
| Esc | 直前に変更した候補や文節の区切りを元に戻す．続けて押すと全文を読みに戻す |
| Backspace | 全文を読みに戻す |
| Delete | 全文を読みに戻し，末尾から入力を続ける |
| F6〜F8 | 選んでいる文節をひらがな・全角カタカナ・半角カタカナに変換 |
| F9 / F10 | 全文を全角英数・半角英数に変換．続けて押すと大文字・小文字・先頭だけ大文字に変換 |
| Control+Backspace | 選んでいる候補を学習から削除 |

Esc で元に戻せる変更は 8 回までです．続けて Space を押して候補を送ったときや，同じ字種のキーを続けて押したときは，まとめて 1 回と数えます．

Backspace で読みに戻すと，ライブ変換がオンでも，読みを変更するまで読みのまま表示します．Enter で読みのまま確定できます．Delete で読みに戻したときは，入力の途中と同じように表示します．

設定の「テンキーの Enter で計算」をオンにすると，テンキーで「12*3」と入力して Enter を押したときに，計算の結果(36)を先頭の候補にして変換します．

## 入力中の候補と予測

設定の「入力中の候補」で表示する設定にすると，入力しながら，読みの変換の候補を窓に表示します．↓ で候補を選び始め，選び始めたあとは数字キーでも選べます．↑ では文字種から選び始めます．選び始めるまでの数字キーは，そのまま数字を入力します．候補が「入力中の候補を表示しない件数」以下のときは窓を表示せず，↓ で変換を始めます．

設定の「入力中の予測」で表示する設定にすると，入力中の語句に続く語句の予測(「えぴ」から「エピソード」)を，変換の候補とは別の小さな窓に表示します．窓は入力中の文字のすぐ右に表示し，入力済みの部分を通常の色で，予測で補う部分を薄い色で表示します．Tab で予測を確定します．予測の窓を表示していないときの Tab は，入力中の候補から選び始めます．Tab の代わりに使うキーは，キー設定の「「もしかして」に修正・予測を確定」で変更できます．

予測には，以前に確定した語句(入力履歴)を優先して表示します．設定の「入力履歴にある予測を優先」をオフにすると，辞書の並びのまま表示します．打ち間違いを修正した読みや「もしかして」で示した読みからも予測します．「もしかして」を示しているあいだの予測には Tab のキーを添えません．Tab で読みを修正すると Tab のキーを添えるので，もう一度 Tab を押すと予測を確定します．設定の「打ち間違いを直した読みからも予測」をオフにすると，読みを修正しているあいだは予測を表示しません．

表示してほしくない予測は，予測の窓に表示しているあいだに Control+Backspace を押すと「予測に表示しない語句」に登録し，次の予測に切り替えます(ひな形が Windows 風・Mac 風・ATOK 風のときは Control+Delete)．登録した語句は，設定の「変換」の「予測に表示しない語句」から削除すると，また表示します．キーはキー設定の「予測に表示しない」で変更できます．

Tab で予測を確定した直後に Backspace を押すと，確定した語句を削除して予測で補う前の読み(「えぴ」)に戻します(ひな形が Windows 風・ATOK 風のときは Control+Backspace)．確定した語句の学習も取り消し，同じ読みのあいだは取り消した予測を表示しません．別のキーを押したあとや，カーソルを動かしたあとの Backspace は通常どおり 1 文字削除します．キーはキー設定の「予測の確定を取り消し」で変更できます．

## 文節の操作

| キー | 操作 |
|---|---|
| Shift+← → | 文節を 1 文字短く・長く |
| Shift+Control+← → | 文節を単語の切れ目まで短く・長く |
| Shift+↓ | 文節の単語の切れ目に番号を表示し，数字キーで分割 |
| Shift+Backspace | 選んでいる文節を消して，その場で入力し直す |
| Option+Space | 入力中に，その位置を文節の区切りにする |

文節を入力し直しているあいだも，分岐図は表示したままです．文節を移動するか Space・Enter を押すと，入力し直した読みを変換します．Esc で元の文節に戻ります．

## 打ち間違いの補正

入力を止めると，打ち間違いを文脈から判断して補正します．

- 補正した部分には点線の下線を引きます．Esc で入力どおりに戻せます．
- 確信が持てないときは補正せず，「もしかして」で候補を示します．Tab で補正します．
- ローマ字で入力した英単語のつづりも補正します(「pthon」→「python」)．

補正しない語句は，設定の「補正」で登録できます．

## 語の意味

変換中に選んでいる語に意味があれば，候補の右にカードで表示します．カードには品詞と，意味(2 つ以上なら番号付き)，使い方の例，同じ読みのほかの語(同音語)が並びます．一覧ではカードが選んでいる候補を指し，分岐図では選んでいる候補から線でつながります．

表示する位置(候補の右・候補の下)，意味の数，品詞・使い方の例・同音語を表示するかは，設定の「変換」の「語の意味」で変えられます．

## 連想変換

入力中に Shift+Space を押すと，選んでいる語と似た意味の語や関連する語を表示します．変換中は Shift+↑ で表示します．↑↓ で語を，← → で意味を選び，Enter で確定します．

設定の「コマンド」で変換マクロをオンにすると，同じキーで，選んでいる語を整えた形(【東京】，東京（とうきょう），|東京《とうきょう》，toukyou など)を「整形」に並べます．形は日付や乱数を含めて自由に足せ，設定の画面で試せます．書き方は[変換マクロと単語に書ける書き方](settings.md#変換マクロと単語に書ける書き方)を参照してください．

## 便利な変換

| 入力 | 候補 |
|---|---|
| 1+2*3= | 7，1+2*3=7 |
| 100-0001 | 東京都千代田区千代田 |
| 21 | ㉑，二一，弐拾壱，ⅩⅩⅠ |
| 2026 | 二〇二六，弐千弐拾六，ⅯⅯⅩⅩⅥ |
| きょう・あした・いま | 2026/10/30，10月30日(金) など |
| なう | なう (2026/10/30 12:34) |
| やじるし | → ← ↑ ↓ |
| -> | → |

数字のあとの「.」「,」はピリオドとカンマ，英数字のあとの「-」はハイフンになります(「3.14」「1,000」「A-1」)．読みの先頭の「-」に数字を続けると「-3」になります．

## 再変換

確定した文字を選んで Control+Shift+R を押すと，読みに戻して変換し直します．

## 手書き入力

設定の「変換」で手書き入力をオンにすると，Control+Option+H(Windows は Ctrl+Alt+H)で手書きの画面を表示します．書いた文字を候補から選んで入力します．

## 絵文字と記号のパレット

Control+Option+E(Windows は Ctrl+Alt+E)で絵文字，Control+Option+K(Windows は Ctrl+Alt+K)で記号，Control+Option+F(Windows は Ctrl+Alt+F)で顔文字のパレットを開きます．入力メニューの「絵文字と記号」からも開けます．パレットを開いているあいだは，打った文字がパレットの検索欄に入ります．

- 読み(「おじぎ」)・名前・英語(「bow」)・ショートコード(「:bow:」)で探せます．ローマ字はかなにして探すので，「ojigi」でも「neko」でも見つかります．英語は途中の文字が抜けていても見つかります(「tmbsup」で 👍)
- 「:bow:」のようにコロンで閉じたショートコードは，そのまま入力します．ローマ字入力では，パレットを開かずに「:bow:」と打っても絵文字になります(打ち始めの「:」から閉じる「:」までを続けて打ったときだけ)
- 記号は「やじるし」「こめじるし」「まるいち」「せっし」など，変換と同じ読みで探せます
- 顔文字は「にこにこ」「しょぼーん」「おじぎ」などの読みで探せます．顔文字は顔文字のパレットで探したときだけ表示し，絵文字や記号の検索結果には混ぜません
- 一覧の上に，ピン留めした文字とよく使う文字を表示します．よく使う文字はパレットを開いたときにだけ並べ替え，開いているあいだは位置を変えません
- 同じ語で何度も選んだ文字は，次にその語で探したときに先頭に表示します

| キー | 動作 |
|---|---|
| 矢印 | 文字を選ぶ |
| Tab / Shift+Tab | 次の分類 / 分類の先頭か前の分類 |
| Control+Tab | 絵文字・記号・顔文字を順に切り替える |
| Enter | 選んでいる文字を入力して閉じる |
| Shift+Enter | 入力して閉じずに続ける |
| Option+Enter(Windows は Alt+Enter) | 肌の色を選ぶ．選んだ色はその絵文字の色として覚える |
| Control+D | ピン留めする・外す |
| Esc | 検索の語を消す．もう一度押すと閉じる |

マウスでも選べます．既定の肌の色は，パレットの右下のボタンで変えられます．使った文字の記録は端末の中にだけ保存し，送信しません．見た目と動きは設定の「絵文字と記号」で変えられます．

## 設定を開く

入力メニューの「設定を開く…」か，Control+Option+カンマ(Windows は Ctrl+Alt+カンマ)で設定画面を開きます．

> [!NOTE]
> cmux など一部のアプリでは，入力メニューの項目が正常に動作しない既知の問題があります．現在修正中です．その場合はキーで設定画面を開いてください．
