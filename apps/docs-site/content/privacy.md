本プライバシーポリシー及び免責事項(以下「本規定」といいます．)は，日本語入力システム「はじめ」における利用者の情報の取扱い並びに開発者の責任の範囲その他の条件について定めるものです．

## 第1章　総則

### 第1条(定義)

本規定において使用する用語の意義は，次の各号に定めるとおりとします．

1. 「本ソフトウェア」とは，日本語入力システム「はじめ」をいい，macOS 版及び Windows 版並びにそれらのソースコード，実行形式のプログラム，インストーラー，辞書その他のデータ，ドキュメント及び更新版を含みます．
2. 「開発者」とは，本ソフトウェアを開発し，公開する者をいいます．
3. 「利用者」とは，本ソフトウェアを入手し，インストールし，又は利用するすべての者をいいます．
4. 「本ライセンス」とは，本ソフトウェアに適用される [MIT License](https://github.com/KikuchiTomo/Hajime/blob/main/LICENSE) をいいます．
5. 「第三者ソフトウェア等」とは，本ソフトウェアに組み込まれ，又は本ソフトウェアが利用するソフトウェア，言語モデル，辞書データ，オペレーティングシステムの機能及びサービスであって，開発者以外の者が権利を有するものをいいます．

### 第2条(適用及び同意)

1. 本規定は，本ソフトウェアの入手，インストール，利用，アンインストールその他本ソフトウェアに関する一切の行為に適用されます．
2. 利用者は，本ソフトウェアをインストールし，又は利用した時点で，本規定に同意したものとみなされます．本規定に同意しない者は，本ソフトウェアをインストールし，又は利用してはなりません．

## 第2章　プライバシーポリシー

開発者は，利用者の情報を取得せず，利用者が入力した内容を利用者の端末の外部に出さないことを，本ソフトウェアにおける個人情報の保護の基本方針とします．

### 第3条(情報の取得)

1. 開発者は，本ソフトウェアを通じて，利用者の個人情報その他の情報を取得しません．
2. 本ソフトウェアは，ネットワークを介して通信する機能を有しません．利用者が入力した文字列，変換の候補，学習データ及び統計情報が，本ソフトウェアにより利用者の端末の外部に送信されることはありません．
3. 本ソフトウェアは，電気通信事業法第27条の12に定める外部送信(利用者の端末に記録された情報を，利用者以外の者に送信させる処理をいいます．)を行わず，Cookie その他これに類する技術により利用者の行動を記録することもありません．

### 第4条(端末内での処理)

1. 本ソフトウェアは，かな漢字変換，打ち間違いの補正その他の入力に関する処理を，すべて利用者の端末内で行います．
2. 本ソフトウェアは，手書き入力の文字の認識に，macOS 版では macOS の文字認識機能を，Windows 版では Windows の手書き認識機能を用います．いずれの認識も，利用者の端末内で行われます．

### 第5条(オペレーティングシステムごとの保護)

1. macOS 版は，App Sandbox の下で動作し，ネットワークに接続する権限を付与されていません．
2. Windows 版において，文字の入力を受け付けるプログラムと変換を行うプログラムとの間の通信は，同一の端末内の名前付きパイプにより行われ，他の端末からの接続は受け付けません．

### 第6条(端末に保存する情報)

1. 本ソフトウェアは，動作のために，次の各号に掲げる情報を利用者の端末に保存します．
   1. 設定　設定画面で変更した値及びユーザー辞書
   2. 学習データ　確定した候補から学習した内容
   3. 統計情報　確定及び補正の回数(入力した文字列を含みません．)
   4. 取り込んだ辞書　辞書の取り込みにより追加した辞書
2. 前項の情報の保存先は，次のとおりとします．

   | 版 | 保存先 |
   |---|---|
   | macOS 版 | `~/Library/Containers/men.haji.inputmethod.Hajime/` |
   | Windows 版 | 設定は `%APPDATA%\haji.men\IME\`，その他の情報は `%LOCALAPPDATA%\haji.men\IME\` |

3. 前2項の情報は，設定の保持，変換の精度の向上その他本ソフトウェアの動作のためにのみ用いられ，開発者がこれを閲覧し，又は利用することはありません．
4. 利用者は，設定画面から学習データ及び統計情報を削除することができ，統計情報の記録を停止することができます．

### 第7条(同期及びバックアップ)

1. 本ソフトウェアは，利用者が同期に用いるフォルダを指定した場合に限り，当該フォルダに設定及び辞書を書き出します．
2. 前項のフォルダの内容を他の端末に複製するのは，利用者が選択した Dropbox，Google Drive，iCloud Drive その他のサービスであり，当該サービスにおける情報の取扱いは，その提供者の定めるところによります．
3. 本ソフトウェアがバックアップとして書き出すファイルは，利用者が指定した場所にのみ保存されます．

### 第8条(第三者への提供)

開発者は，利用者の情報を取得しないため，これを第三者(外国にある第三者を含みます．)に提供し，又は第三者と共同して利用することはありません．
