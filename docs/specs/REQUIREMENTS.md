# 要件

s90.tokyo IME が満たす要件の一覧です．機能の仕様書(`docs/specs/<id>-*.md`)はここにある ID を参照して書きます．
受け入れ条件は，テストか手動の確認手順に落とせる粒度で書きます．

対象は macOS と Windows です．Linux などは後で足す前提で，プラットフォームに依存しない部分を `core/` に寄せます(`docs/dev/ARCHITECTURE.md`)．

## R-01 ライブ変換

打っている途中の読みを，確定キーを押さなくても漢字かな混じりで表示する．

- 受け入れ条件
  - ローマ字・かな入力のどちらでも動く
  - 変換結果の表示は，キーを押してから 1 フレーム(16ms)以内を目標にする．間に合わないときは読みのまま表示し，結果が出たら置き換える
  - 句読点・Enter・Space で，表示中の結果を確定または候補選択に移れる
  - アプリごとの設定(R-06)でライブ変換を切れる

## R-02 タイプミスの自動補正

日本語と英語のタイプミスを，打っているあいだに補正する．補正はいつでも元に戻せる．

- 補正の種類
  - かなに化けた英単語: `pyてょn` → `python`(ローマ字入力のまま英単語を打ってしまった場合)
  - 英単語の綴り: `pthon` → `python`
  - 日本語のローマ字の打ち間違い: `konnnitiha` の `nnn` のような重複，隣のキーの押し間違い
- 受け入れ条件
  - 補正したことが見た目でわかる(`docs/dev/DESIGN-SYSTEM.md` の補正の表示)
  - 補正の直後に Space を押すと，打ったままの文字列に戻る．候補一覧でも打ったままの文字列を 2 番目に出す
  - 補正の辞書と判定は端末の中だけで行う．入力した文字列を外部に送らない(`docs/dev/SECURITY-MODEL.md`)
  - 補正の強さ(切る・控えめ・積極的)を設定できる

## R-03 変換候補の上の「種類」の行

変換中，候補一覧の上に文字の種類の行を出す．macOS 標準の日本語入力と同じく，上キーで移れる．

- 種類: そのまま(ひらがな)・カタカナ・半角カタカナ・全角英数・半角英数
- 受け入れ条件
  - 候補一覧の先頭で上キーを押すと種類の行に移り，左右で選び，下キーで候補一覧に戻る
  - 種類の行の項目にもショートカット(例: 既定は macOS と同じ Control+K でカタカナ)を割り当てられる
  - 種類の行を出さない設定がある

## R-04 ¥ と \ の扱い

JIS キーボードの ¥ キーで何を入れるかを，設定ひとつで変えられる．

- 受け入れ条件
  - 既定はバックスラッシュ(`\`)．プログラミングで困らないことを優先する
  - 「常に ¥」「常に \」「プログラミング用のアプリだけ \」を選べる
  - Option+¥ で逆の文字を入れられる
  - 全角の ¥ と半角の ¥ を取り違えない

## R-05 入力方式

- ローマ字入力
- かな入力(JIS かな配列)
- 英語のまま入力(以下 EN 入力)．英語配列のまま打ち，読みとして解釈できる並びには日本語の候補を出す
  - 例: `konnnitiha` と打つと，候補に「こんにちは」を出す
  - 設定で，EN 入力でもライブ変換させられる
- 受け入れ条件
  - 方式の切り替えはメニューとショートカットの両方でできる
  - EN 入力で日本語の候補を出しても，Space や Enter の既定の動きは英語入力と同じ(候補は Tab などの明示した操作で選ぶ)

## R-06 プログラミング中に邪魔をしない

- アプリ(バンドル ID・実行ファイル名)ごとにプロファイルを割り当てる．エディタ・IDE・ターミナルには既定のプロファイルを用意する
- プログラミング用のプロファイルの既定
  - 記号は半角(`()[]{}<>;:'"` など)
  - 英単語の補正(R-02)は日本語の文中にあるときだけ行い，識別子らしい並び(`camelCase`，`snake_case`，`a.b`)は補正しない
  - ライブ変換は控えめ(英数字が続くあいだは確定しない)
- 受け入れ条件
  - Vim のノーマルモードに戻る Escape で，入力方式を英数に戻す設定がある
  - 変換中でないときに，IME がキーを横取りしない

## R-07 コマンド入力

ターミナルやコマンドパレットでコマンドを打つときに，日本語入力のままでも困らないようにする．

- 受け入れ条件
  - ターミナルのプロファイルでは，行頭から英数字と記号が続くあいだは確定済みの英字として流す
  - 引用符の中など，日本語が来そうな位置では日本語の候補を出す
  - コマンドパレット(VS Code など)を開いたときの入力欄も対象にできる
