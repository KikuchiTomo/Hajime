title: Windows に入れる

## 前提

- Windows 10 22H2 以降(64 ビット)
- 管理者の権限(入れるときだけ)

## 手順

1. GitHub の Actions の `windows` のワークフローの実行結果から，`s90-tokyo-ime-windows` を受け取り，中の `s90-tokyo-ime.msi` を取り出します
2. `s90-tokyo-ime.msi` を開いて入れます．まだ署名していないので，SmartScreen の警告が出たら「詳細情報」から「実行」を選びます
3. 一度サインアウトしてサインインし直します．ログオンのたびに変換エンジン(`s90-engine-host.exe`)が動き始めます
4. 設定 > 時刻と言語 > 言語と地域 で「日本語」の「言語のオプション」を開き，「キーボードの追加」から「s90.tokyo IME」を選びます
5. Windows キー + Space で s90.tokyo IME に切り替えます
6. メモ帳で `kyouhaiitenkidesune` と打つと「今日はいい天気ですね」と表示されます．Enter で確定します

## 入力メニュー

タスクバーの「あ」「A」をクリックすると，日本語と英数が切り替わります．右クリックのメニューから，ライブ変換のオン・オフと設定を開くを選べます．入力方式は設定の画面とキー(Alt+かな)で切り替えます．

## 設定を変える

スタートメニューの「s90.tokyo IME の設定」を開くと，macOS 版と同じく左の一覧からページを選んで設定を変えられます．上の検索欄に項目の名前を入れると，その項目のあるページだけが並びます．既定から変えた項目には右に「既定に戻す」のボタンが出ます．

今あるページは 入力・変換・補正・英語と日本語・ローマ字・キー設定・除外設定・ユーザー辞書・外観・統計・バックアップ・情報 です．記号・同期のページ，外観のカスタムテーマ，ファイルの読み込みと書き出しはまだありません．それらの項目は，バックアップのページの「設定ファイルを開く」で開く `settings.json` を直接書き換えます．形式は macOS 版と同じで，保存すると 2 秒ほどで反映されます．

キー設定の表のキーは，「Ctrl Shift Space」のように修飾キー(Ctrl・Alt・Shift)とキーの名前を空白で区切って入力します．除外設定のアプリは実行ファイルの名前(`code.exe` など)で指定します．

| ファイル | 置き場所 |
|---|---|
| 設定 | `%APPDATA%\s90.tokyo\IME\settings.json` |
| 学習データ・使い方の記録・取り込んだ辞書 | `%LOCALAPPDATA%\s90.tokyo\IME\` |

## 取り除く

設定 > アプリ > インストールされているアプリ から「s90.tokyo IME」を選んでアンインストールします．設定と学習データは残るので，要らなければ上の置き場所のフォルダを消します．

## Windows 版でまだ使えないもの

- 英単語の綴りの補正
- 設定と辞書の同期
- EUC-JP の辞書の取り込み
