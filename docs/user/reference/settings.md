---
title: 設定の一覧
description: 設定の画面とメニューで変えられる項目，既定値，ほかの日本語入力の設定との対応
---

設定は，入力メニュー(メニューバーの「あ」)の「設定を開く…」か，⌃⌥,(Control+Option+カンマ)で開く画面で変えます．入力メニューには，ほかに「ライブ変換」の切り替えだけを置いています．ライブ変換は ⌃⌥L でも切り替えられます．

cmux など一部のアプリは，入力メニューの項目を選んでも IME に取り次がないため，項目を選んでも何も起きません．そのときはキーで開いてください(2026-10-26 に実機のログで確かめた)．キーは「キー操作」で変えられます．設定は `~/Library/Application Support/tokyo.s90.ime/settings.json` に保存します．

項目は，Google 日本語入力・ATOK・macOS の日本語入力・Microsoft IME の設定を調べて選びました．4 製品すべてにある項目と，日本語の入力の仕方を変える項目を入れています．

## 入力

| 項目 | 既定 | 選べる値 |
|---|---|---|
| 入力方式 | ローマ字入力 | ローマ字入力 / かな入力 / 英字入力 |
| キー配列 | システムの設定に従う | システムの設定に従う / ABC / US / Dvorak / Dvorak - QWERTY ⌘ / Colemak |
| 句読点 | 、。 | 、。 / ，． / 、． / ，。 |
| [ ] キーで入力する括弧 | 「」 | 「」 / ［］ |
| / キーで入力する文字 | ・ | ・ / ／ |
| ¥ キーで入力する文字 | 常に \ | 常に \ / 常に ¥ / エディタとターミナルだけ \ |
| スペース幅 | 半角 | 半角 / 全角．Shift+Space で逆の幅 |
| 数字幅 | 半角 | 半角 / 全角 |
| 句読点で確定 | オフ | |
| 番号キーで候補を選択 | オン | |
| 入力モードの切り替えを表示 | オン | |

かな入力は JIS かな配列です．キー配列は，ローマ字入力と英字入力で打つ英字の配列です．かな入力はキーの位置でかなを決めるので，この設定によりません．キー配列を変えると，次に入力欄を選んだときから反映されます．

英字入力では，打った英字をそのまま見せ，ローマ字として読める 4 文字以上の並びには日本語の候補を添えます．Tab で日本語にし，Space・Enter・記号は英語の入力と同じに動きます．入力方式は Option+かな キーで順に切り替えられます(ローマ字 → かな → 英字)．

エディタとターミナル(VS Code，Xcode，JetBrains，ターミナルなど)では，括弧などの記号とスペースは設定によらず半角のまま入れます．

## 変換

| 項目 | 既定 | 選べる値 |
|---|---|---|
| ライブ変換 | オン | |
| 候補の表示 | 分岐図 | 分岐図 / 一覧 |
| 候補の上に文字種の行を表示 | オン | 一覧のときに使う |
| タイプミスの修正 | 英単語と日本語 | オフ / 英単語のみ / 英単語と日本語 |
| 日付と時刻に変換 | オン | 「きょう」「いま」など |
| 記号に変換 | オン | 「やじるし」など |
| 絵文字に変換 | オン | |
| 学習 | 学習する | 学習する / 学習結果を使うが，新しく学習しない / 学習しない |

「学習結果を消去」で，確定した候補から学んだ内容をすべて消せます．

### タイプミスの修正

「英単語と日本語」では，ライブ変換で打鍵が 0.8 秒止まったときに，打ったキー全体を Zenzai で見直します．

- 確かなときは直して見せます．直した文には点線の下線を引き，入力位置の下に「直しました　Esc で「…」に戻す」と出します．Esc で打ったままに戻せます．そのまま打ち続ければ，直した文に続けて入ります
- 確かでないときは直さず，「もしかして「…」　Tab で直す」と出すだけにします
- 近くのキーの打ち間違い，余分なキー，2 つのキーの入れ替わり，同じキーを 2 回打ってしまった誤り(`koonnnitiha` → こんにちは)を直します．キーを打ち忘れた誤りは直せません
- 見直したあとに打ち続けると，案内は消えます．点線の下線は残り，Esc で戻せます
- Esc で戻したり「もしかして」を取り下げたりした文は，確定するまで見直し直しません
- 分岐図を開くと，直した文節の 2 番目以降に，打ったままの候補も出します．どちらも選べます
- ターミナルの行の頭では見直しません(コマンドの名前を書き換えないため)
- ライブ変換を切っているときは，Space で変換するときに見直します

## ユーザー辞書

読み(ひらがな)と単語を登録します．読みが一致すると，その単語を候補の先頭に出します．「読み<タブ>単語」の行が並んだテキストファイルをインポートできます．Google 日本語入力と ATOK でエクスポートしたファイルはこの形です．登録できるのは 10,000 語までです．

## 統計

確定した回数，Space で変換した回数，選び直した文節の数，タイプミスや英単語を修正した回数と取り消した回数だけを，この Mac の中(`~/Library/Application Support/tokyo.s90.ime/usage.json`)に記録します．入力した文字は記録せず，外部にも送信しません．「第 1 候補のまま確定した割合」は，候補の表示やライブ変換の見せ方を見直すのに使います．「入力の統計を記録」をオフにすると記録を止め，「統計を消去」で消せます．

## ローマ字

ローマ字の変換表に組み合わせを追加できます．例えば `wyi` に ゐ を割り当てられます．標準の表と同じ入力は，追加したものが優先されます．入力は英小文字・「-」・「'」で 4 文字まで，出力は 6 文字まで，500 個まで追加できます．

## キー

キーの割り当ては次のとおりです．変換中(分岐図)の操作のキーは，設定の「キー操作」で変えられます(1 つの操作に複数のキーを割り当てられます)．Enter・Esc・Backspace・数字キーは変えられません．

| キー | 読みを組み立てているとき |
|---|---|
| Space | 分岐図を出す．出ているときは次の候補 |
| ↓ ↑ | 分岐図の下の枝(変換の候補)と上の枝(文字種)をたどる |
| ← → | 文節を移る．Shift と一緒に押すと文節の長さを変える．押したらどうなるかを分岐図の足元に出す |
| Tab | 分岐図では，確信の低い次の文節へ移る．「もしかして」が出ているときは直す．英字入力では日本語にする |
| 1〜9 | 候補を選ぶ |
| Enter | 確定する |
| Esc | 分岐図から読みに戻る．タイプミスを直したときは打ったままに戻し，「もしかして」が出ているときは取り下げる |
| F6 / Ctrl+J | ひらがな |
| F7 / Ctrl+K | カタカナ |
| F8 / Ctrl+; | 半角カタカナ |
| F9 / Ctrl+L | 全角英数 |
| F10 / Ctrl+: | 半角英数 |
| Option+かな | 入力方式を切り替える(ローマ字 → かな → 英字) |

## アプリ別

アプリごとにモードを決めます．バンドル ID の前方一致で決め，上にあるものほど優先します．既定ではエディタ(VS Code，Cursor，JetBrains，Xcode など)とターミナル(ターミナル，iTerm2，Ghostty など)を登録してあります．

| モード | 動き |
|---|---|
| 標準 | 記号を全角で入れる |
| エディタ | 記号とスペースを半角のまま入れる |
| ターミナル | エディタと同じに加え，行の頭でコマンドの名前を打って Space を押すと，その行を英字のまま流す(引用符の中と # の後ろは日本語) |

「Escape で英数に切り替え」をオンにすると，Vim のノーマルモードに戻るときに英数に切り替わります．既定ではオフです．

## 外観

| 項目 | 既定 | 選べる値 |
|---|---|---|
| テーマ | 標準 | 標準 / 和紙 / 北欧 / ネオン / 端末 / 高コントラスト / プラチナ / 夜のデスク |
| 候補の文字サイズ | 15 | 12〜24 |

標準はすりガラスの見た目で，ライトとダークのどちらにも合わせます．和紙・北欧・ネオン・端末・高コントラストは色と書体の違う角丸の見た目，プラチナと夜のデスクは四角い枠の古い Mac 風の見た目です．

## まだ無い項目と，入れない項目

ほかの日本語入力にあって，s90.tokyo IME にまだ無い項目です．

| 項目 | 状態 |
|---|---|
| ローマ字テーブルの編集 | 作る予定 |
| US キーボードで入力方式を切り替えるショートカット | 作る予定．かなキーの無いキーボードでは設定の画面で切り替える |
| キー割り当てのプリセット(MS-IME 風・ATOK 風・ことえり風) | 作る予定．変換中のキーは「キー操作」で 1 つずつ変えられる |
| 予測候補(打っている途中に続きを出す) | 入れない．打鍵を止めさせ，文が平凡になるという研究があるため(docs/dev/research/list-free-input.md) |
| クラウドの辞書・候補，使用統計の送信 | 入れない．入力した内容を端末の外に出さないため(docs/dev/SECURITY-MODEL.md) |
| 校正支援(ら抜き言葉・敬語など)，連想変換，郵便番号変換 | 入れない．辞書のデータが要り，日本語の入力を速くする目的から外れるため |
| 候補ウィンドウを出すまでの変換回数 | 入れない．分岐図は確信の低い文節だけを見せるので，同じ目的を別の形で満たしている |
