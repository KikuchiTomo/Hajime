---
title: 設定の一覧
description: 設定の画面とメニューで変えられる項目，既定値，ほかの日本語入力の設定との対応
---

設定は，入力メニュー(メニューバーの「あ」)の「設定を開く…」で開く画面で変えます．よく使う項目は入力メニューからも直接変えられます．設定は `~/Library/Application Support/tokyo.s90.ime/settings.json` に保存します．

項目は，Google 日本語入力・ATOK・macOS の日本語入力・Microsoft IME の設定を調べて選びました．4 製品すべてにある項目と，日本語の入力の仕方を変える項目を入れています．

## 入力

| 項目 | 既定 | 選べる値 |
|---|---|---|
| 入力方式 | ローマ字入力 | ローマ字入力 / かな入力(JIS かな配列) / 英語のまま入力 |
| 句読点 | 、。 | 、。 / ，． / 、． / ，。 |
| [ ] で入れる括弧 | 「」 | 「」 / ［］ |
| / で入れる文字 | ・ | ・ / ／ |
| ¥ キーで入力する文字 | 常に \ | 常に \ / 常に ¥ / エディタとターミナルだけ \ |
| 空白 | 半角 | 半角 / 全角．Shift+Space で逆の幅 |
| 数字 | 半角 | 半角 / 全角 |
| 句読点を打ったら確定する | 切る | |
| 番号キーで候補を選ぶ | 入れる | |
| 日本語と英数を切り替えたときにモードを出す | 入れる | |

英語のまま入力では，打った英字をそのまま見せ，ローマ字として読める 4 文字以上の並びには日本語の候補を添えます．Tab で日本語にし，Space・Enter・記号は英語の入力と同じに動きます．入力方式は入力メニューからも切り替えられます．

エディタとターミナル(VS Code，Xcode，JetBrains，ターミナルなど)では，括弧などの記号と空白は設定によらず半角のまま入れます．

## 変換

| 項目 | 既定 | 選べる値 |
|---|---|---|
| ライブ変換 | 入れる | |
| 候補の出し方 | 分岐図 | 分岐図 / 一覧 |
| 候補の上に種類の行を出す(一覧のとき) | 入れる | |
| タイプミスの補正 | 標準 | 切る / 控えめ(英単語だけ) / 標準(綴りの誤りと日本語の打ち間違いも直す) |
| 「きょう」「いま」などを日付と時刻にする | 入れる | |
| 「やじるし」などの読みから記号を出す | 入れる | |
| 読みから絵文字を出す | 入れる | |
| 学習 | 学習する | 学習する / 学習した内容は使うが新しく学習しない / 学習しない |

「学習した内容を消す」で，確定した候補から学んだ内容をすべて消せます．

## ユーザー辞書

読み(ひらがな)と語を登録します．読みが一致すると，その語を候補の先頭に出します．「読み<タブ>語」の行が並んだテキストのファイルを取り込めます．Google 日本語入力と ATOK が書き出すファイルはこの形です．登録できるのは 10,000 語までです．

## 使い方の記録

確定した回数，Space で候補を開いた回数，選び直した文節の数，打ち間違いや英単語を直した回数と戻した回数だけを，この Mac の中(`~/Library/Application Support/tokyo.s90.ime/usage.json`)に記録します．入力した文字は記録せず，どこにも送りません．「選び直さずに確定した割合」は，候補の出し方やライブ変換の見せ方を見直すのに使います．「使い方を記録する」を切ると記録を止め，「記録を消す」で消せます．

## アプリ

アプリごとに扱いを決めます．アプリの ID(バンドル ID)の前方一致で決め，上にある規則ほど優先します．既定ではエディタ(VS Code，Cursor，JetBrains，Xcode など)とターミナル(ターミナル，iTerm2，Ghostty など)を登録してあります．

| 扱い | 動き |
|---|---|
| ふつう | 記号を全角で入れる |
| エディタ | 記号と空白を半角のまま入れる |
| ターミナル | エディタと同じに加え，行の頭でコマンドの名前を打って Space を押すと，その行を英字のまま流す(引用符の中と # の後ろは日本語) |

「日本語のモードで Escape を押したら英数にする」を入れると，Vim のノーマルモードに戻るときに英数に切り替わります．既定では切っています．

## 見た目

| 項目 | 既定 | 選べる値 |
|---|---|---|
| 外観 | 自動 | 自動(ライトはプラチナ，ダークは夜のデスク) / プラチナ / 夜のデスク / システム |
| 候補の文字の大きさ | 15 | 12〜24 |

## まだ無い項目と，入れない項目

ほかの日本語入力にあって，s90.tokyo IME にまだ無い項目です．

| 項目 | 状態 |
|---|---|
| ローマ字テーブルの編集 | 作る予定 |
| 入力方式を切り替えるショートカット | 作る予定．今は入力メニューと設定の画面で切り替える |
| キー割り当ての編集とプリセット(MS-IME 風・ATOK 風・ことえり風) | 作る予定 |
| 予測候補(打っている途中に続きを出す) | 入れない．打鍵を止めさせ，文が平凡になるという研究があるため(docs/dev/research/list-free-input.md) |
| クラウドの辞書・候補，使用統計の送信 | 入れない．入力した内容を端末の外に出さないため(docs/dev/SECURITY-MODEL.md) |
| 校正支援(ら抜き言葉・敬語など)，連想変換，郵便番号変換 | 入れない．辞書のデータが要り，日本語の入力を速くする目的から外れるため |
| 候補ウィンドウを出すまでの変換回数 | 入れない．分岐図は迷う文節だけを見せるので，同じ目的を別の形で満たしている |
