title: 設定の一覧
description: 設定の画面とメニューで変えられる項目と既定値
---

設定は，入力メニュー(メニューバーの「あ」)の「設定を開く…」か，⌃⌥,(Control+Option+カンマ)で開く画面で変えます．入力メニューには，ほかに「ライブ変換」の切り替えと「手書き入力」(手書き入力を使う設定のとき)を置いています．ライブ変換は ⌃⌥L でも切り替えられます．

画面の左の一覧は，「入力と変換」(入力・変換・補正・英語と日本語・ローマ字・キー設定・除外設定)，「辞書と記号」(ユーザー辞書・記号)，「見た目」(外観)，「データ」(統計・同期・バックアップ)，「このアプリについて」(情報)に分けています．上の検索欄に項目の名前を入れると，その項目のあるページだけを残します．

### 決まりの一覧

置き換え・修正しない語句・ローマ字・ユーザー辞書・記号は，同じ形の一覧で編集します．

- 上の欄に入れて「追加」(Return でも足せます)．形が合わないときは欄の下に理由を出し，追加できません．同じ入力の決まりがあるときは，上書きすることを欄の下に出します
- 行をダブルクリックすると上の欄で書き換えられます(「更新」で保存，「キャンセル」で取りやめ)
- 行を選んで「削除」か Delete キーで消します．右クリックのメニューからも編集・削除できます
- 列の見出しを押すと，その列で並べ替えます．下の検索欄で絞り込めます
- 「インポート…」「エクスポート…」で入力と出力をタブで区切ったテキストファイルを読み書きします(修正しない語句は 1 行に 1 つ)．形の合わない行は読みません

cmux など一部のアプリは，入力メニューの項目を選んでも IME に取り次がないため，項目を選んでも何も起きません．そのときはキーで開いてください．キーは「キー設定」で変えられます．設定は `~/Library/Application Support/tokyo.s90.ime/settings.json` に保存します．

日本語と英数を切り替えるキー(英数・かな・半角/全角・変換・無変換や，好きなキーの組み合わせ)は「キー設定」で決めます(下の「キー設定」)．

かな入力は JIS かな配列です．キー配列は，ローマ字入力と英字入力で打つ英字の配列です．かな入力はキーの位置でかなを決めるので，この設定によりません．キー配列を変えると，次に入力欄を選んだときから反映されます．

英字入力では，打った英字をそのまま見せ，ローマ字として読める 4 文字以上の並びには日本語の候補を添えます．Tab を押すと分岐図を開き，変換を選んで Enter で確定します．Esc で英字に戻ります．語の途中の「-」は伸ばし棒として読みます(ra-men → ラーメン)．大文字を含む語には日本語の候補を出しません．ターミナルでは，日本語の候補が無いときの Tab はそのまま補完に使えます．Space・Enter・記号は英語の入力と同じに動きます．「英字入力のライブ変換」をオンにすると，ローマ字として読めて英語の辞書にない語を日本語にして見せます．日本語にした語は Space か Enter で確定し(空白や改行は入れません)，Esc で英字に戻ります．

英字入力(自動)では，英語で打ちながら，日本語にできる語を語ごとに見分けて日本語にします(kyouhaiitenki → 今日はいい天気，hello はそのまま)．判別方法は下の「英語と日本語」で変えられます．日本語にした語の扱いは英字入力のライブ変換と同じです．

入力方式は，設定の画面で選ぶか，Option+かな キー(キー設定の「入力方式の切り替え」)で順に切り替えられます(ローマ字 → かな → 英字 → 英字(自動))．キー設定の表では，方式ごとのコマンド(ローマ字入力・かな入力・英字入力・英字入力(自動))を好きなキーに割り当てられます．

エディタとターミナル(VS Code，Xcode，JetBrains，ターミナルなど)では，括弧などの記号とスペースは設定によらず半角のまま入れます．

### タイプミスの修正

「英単語と日本語」では，ライブ変換で打鍵が 0.8 秒止まったときに，打ったキー全体を Zenzai で見直します．

- 確かなときは直して見せます．直した文には点線の下線を引き，入力位置の下に「修正しました　Esc で「…」に戻す」と出します．Esc で打ったままに戻せます．そのまま打ち続ければ，直した文に続けて入ります
- 確かでないときは直さず，「もしかして「…」　Tab で直す」と出すだけにします
- 近くのキーの打ち間違い，余分なキー，2 つのキーの入れ替わり，同じキーを 2 回打ってしまった誤り(`koonnnitiha` → こんにちは)，キーの打ち忘れ(`tutta` を `tuta` と打つなど)を直します
- 見直したあとに打ち続けると，案内は消えます．点線の下線は残り，Esc で戻せます
- Esc で戻したり「もしかして」を取り下げたりした文は，確定するまで見直し直しません
- 分岐図を開くと，直した文節の 2 番目以降に，打ったままの候補を「入力のまま」の印付きで出します．「もしかして」と示しているときは，その文節に直した候補を「修正」の印付きで出します．選べばその文節だけを直す・戻すことができます
- ターミナルの行の頭では見直しません(コマンドの名前を書き換えないため)
- ライブ変換がオフになっているときは，Space で変換するときに見直します
- Space を押したときにまだ見直し終わっていなければ，変換はすぐに出し，見直し終わったときに(そのあいだにキーを押していなければ)直した変換か「もしかして」に入れ替えます

## ユーザー辞書

読み(ひらがな)と単語を登録します．読みが一致すると，その単語を候補の先頭に出します．読みと単語をタブで区切ったテキストファイルをインポートできます．登録できるのは 10,000 語までです．同じ読みに別の単語を登録できます．読みと単語の両方が同じ語は重ねて登録しません．

## 取り込んだ辞書

辞書のページの「取り込んだ辞書」で，大きな辞書のファイルを丸ごと取り込めます．専門用語の辞書やネットの用語の辞書のように，数十万語ある辞書でも使えます．取り込んだ語は，文の中の語としても変換の候補に出ます．分岐図では，選んでいる候補がどの辞書の語かを足元に出します．

| 項目 | 内容 |
|---|---|
| 取り込める形式 | 読み・単語・品詞をタブで区切ったテキスト(品詞は無くてもよい)，SKK の辞書(送り仮名のない語だけ)，macOS のユーザ辞書を書き出した plist |
| 文字コード | UTF-8，UTF-16，Shift_JIS，EUC-JP．中身から見分けます |
| 優先度 | 上にある辞書ほど優先します．矢印のボタンで並べ替えます |
| 名前と分野 | 一覧に出す名前と，「電気」「法律」などの分野を付けられます．分野を付けると，分岐図には分野を出します |
| 使う場面 | 常に，選んだアプリ，文脈に合わせる．「選んだアプリ」はそのアプリでだけ使います．「文脈に合わせる」はふだんは優先度を下げ，その辞書の単語を最近 2 回以上確定すると上げます |
| 再読み込み | 元のファイルが新しくなったときに，名前と使う場面を残したまま語を入れ替えます |

取り込める辞書は 32 個まで，1 つの辞書のファイルは 256MB までです．取り込んだ語は `~/Library/Application Support/tokyo.s90.ime/dictionaries/` に置き，起動時には読みません．初めて変換に使うときに開きます．

## 再変換

確定した文字を選んで再変換のキーを押すと，選んだ文字を読みに戻して変換し直します．読みは OS の日本語の解析で求めます(macOS は CFStringTokenizer，Windows は IFELanguage)．

- キーは，何も入力していないときの Ctrl+Shift+R と 変換 です．「キー設定」の「再変換」で変えられます
- 候補を選んで確定すると，選んでいた文字を置き換えます．Esc を押すと元の文字に戻します
- 読みを求められない文字(英字や記号だけなど)と，長い文字は再変換しません

## 連想変換

変換中の語句と似た意味の単語や関わりのある単語を，ふつうの候補とは別の一覧に出します．

- 入力中に Shift+Space を押すと，変換してから選んでいる文節を連想の一覧にします．変換中は Shift+↑ で連想の一覧に切り替えます(Windows 風・Mac 風のひな形では Option+↑)．キーは「キー設定」の「連想変換」で変えられます
- 一覧の上には元の語句と意味の説明を出し，意味ごとに単語を分けます．↓ ↑ で単語を，← → で意味を選び，Enter で確定します．Esc か同じキーで元の変換に戻ります
- 候補の表示が分岐図なら分岐図の枝に，一覧なら一覧に出します
- 選んでいる単語のまま文字を打ち続けたり，文節を移ったりすることもできます．連想から選んだ単語は学習しません

連想の単語は，同梱の日本語 WordNet と，変換のページの「連想の辞書」に取り込んだ辞書から引きます．

| 項目 | 内容 |
|---|---|
| 取り込める形式 | 1 行に同じ意味の単語を並べたテキスト．タブで区切るときは先頭の列に意味の説明(空でよい)を書き，2 列目から単語を並べます．タブの無い行は「,」か「、」で区切った単語の並びとして読みます．「#」で始まる行は読みません |
| 文字コード | UTF-8，UTF-16，Shift_JIS，EUC-JP．中身から見分けます |
| 優先度 | 上にある辞書の連想ほど先に出します |

取り込める連想の辞書は 8 個まで，1 つのファイルは 64MB までです．取り込んだ辞書は `~/Library/Application Support/tokyo.s90.ime/associations/` に置き，同期のフォルダには運びません．

## 統計

確定した回数，Space で変換した回数，選び直した文節の数，タイプミスや英単語を修正した回数と取り消した回数だけを，この Mac の中(`~/Library/Application Support/tokyo.s90.ime/usage.json`)に記録します．入力した文字は記録せず，外部にも送信しません．「第 1 候補のまま確定した割合」は，候補の表示やライブ変換の見せ方を見直すのに使います．「入力の統計を記録」をオフにすると記録を止め，「統計を消去」で消せます．

## ローマ字

ローマ字の変換表に組み合わせを追加できます．例えば `wyi` に ゐ を割り当てられます．標準の表と同じ入力は，追加したものが優先されます．入力は英小文字・「-」・「'」で 4 文字まで，出力は 6 文字まで，500 個まで追加できます．

## キー設定

すべての操作のキーを「キー設定」の表で決めます．表の 1 行は「状態・キー・コマンド」の組で，行は好きなだけ足せます．1 つのコマンドに複数のキーを割り当てることも，同じキーを状態ごとに違うコマンドにすることもできます．

### 表の使い方

- 新しい行: 状態とコマンドを選び，キーの欄を押してから割り当てたいキーを押します．修飾キー(⌃⌥⇧⌘)はいくつでも組み合わせられます．キーの欄の右の ⌄ からは，押しにくいキー(半角/全角・変換・無変換・F13 以降など)と修飾キーを選べます
- 行の状態・キー・コマンドは表の中でそのまま変えられます．行を選んで「削除」か Delete キーで消し，右クリックで複製できます
- 検索: コマンドの名前・状態・キーの名前で絞り込みます．「キーで検索」を押してからキーを押すと，そのキーの行だけを出します
- ひな形: 標準・Windows 風・Mac 風・Emacs 風・Vim 風から読み込めます．変えた表を置き換えるときは確かめます．「既定に戻す」で標準に戻ります
- 同じ状態の同じキーの行が 2 つあると，下の行を使い，上の行に ⚠ を出して薄く見せます．状態を選んだ行は「いつでも」の行より優先し，「いつでも」の行には ⓘ を出します．修飾キーの無い文字のキーを入力文字なし・入力中・いつでも に置くと，その文字を打てなくなるので印を出します
- 入力中か変換中に「確定」か「取り消し」のキーが無いときは，表の上に知らせます

### 状態

| 状態 | いつ |
|---|---|
| いつでも | 下の 4 つの状態のうち，コマンドが効く状態すべて |
| 入力文字なし | 日本語入力で何も組み立てていない |
| 入力中 | 読みを組み立てている(ライブ変換の表示と「もしかして」の案内を含む) |
| 変換中 | 分岐図か候補の一覧で候補を選んでいる(文字種の行を含む) |
| 英数 | 英数入力．切り替えのコマンドだけが効き，ほかのキーはアプリに渡す |

### コマンド

| まとまり | コマンド |
|---|---|
| 入力モード | 日本語入力に切り替え・英数入力に切り替え・日本語と英数の切り替え・入力方式の切り替え・ローマ字入力・かな入力・英字入力・英字入力(自動)・取り消して英数入力に |
| 空白 | 空白を入力(スペース幅の設定に従う)・逆の幅の空白を入力・半角空白を入力・全角空白を入力 |
| 入力 | 変換・学習を使わずに変換・左の文字を削除・ここで区切る・「もしかして」に修正・再変換 |
| 文字種 | ひらがな・全角カタカナ・半角カタカナ・全角英数・半角英数に変換・かなの種類を切り替え |
| 候補 | 次の候補・前の候補・次の候補のページ・前の候補のページ・先頭の候補・末尾の候補・連想変換 |
| 文節 | 右の文節・左の文節・先頭の文節・末尾の文節・誤りやすい次の文節・誤りやすい前の文節・文節を長く・文節を短く・文節を単語ごとに長く・文節を単語ごとに短く・文節を区切る |
| 確定と取り消し | 確定・先頭の文節だけ確定・取り消し・読みに戻す |
| 学習 | 候補を学習から削除・最後の学習を取り消し |
| そのほか | 設定を開く・ライブ変換の切り替え・手書き入力 |

組み立て中に空白を入れるコマンドを押すと，組み立て中の文字を確定してから空白を入れます．「学習を使わずに変換」で確定した語は学習しません．「最後の学習を取り消し」は入力した文字を消さずに，最後に確定した語の学習だけを取り消します．数字キーで候補を選ぶ動きは表に入れず，「番号キーで候補を選択」に従います．英字入力では，読みを組み立てていないとき(英字を打っている途中と何も打っていないとき)は英語の入力と同じに動き，表は入力モードとそのほかのコマンドにだけ使います．

### ひな形

| ひな形 | 特徴 |
|---|---|
| 標準 | 上の表 |
| Windows 風 | Space・変換で変換，無変換でかなの種類を切り替え，Ctrl+I・O・P・T・U で字種，F2 で学習を使わずに変換，Ctrl+↓ で先頭の文節だけ確定，Ctrl+Shift+Space で全角空白 |
| Mac 風 | Ctrl+J・K・L・;・: と Option+Z・X・C・A・S で字種，Option+Space で全角空白，Ctrl+N・P で候補，Ctrl+B・F で文節 |
| Emacs 風 | 標準に加えて Ctrl+N・P で候補，Ctrl+F・B で文節，Ctrl+A・E で先頭・末尾の文節，Ctrl+G で取り消し，Ctrl+M で確定 |
| Vim 風 | 標準に加えて，変換中に H・L で文節，J・K で候補，Shift+H・L で文節の長さ，Shift+J・K で候補のページ，W・B で誤りやすい文節，0・$ で先頭・末尾の文節，Ctrl+[ で取り消し．文字のキーは変換中にだけ置くので，入力中は打った文字のまま．入力文字なしの Esc は表に置かないので，「Esc で英数に切り替え」の設定がそのまま効く |

ひな形はどれも，英数・かな・半角/全角・Option+かな と，設定を開くなどのキーと，連想変換のキーをそろえてあります．

### 古い設定から

以前のバージョンの「キー操作」と「切り替えのキー」の設定は，初めて起動したときにこの表に移します．既定から変えていなかった項目は標準の表のままにします．
## 補正

| 項目 | 既定 | |
|---|---|---|
| 英単語 | オン | 英単語の補正(「pyてょn」「pthon」→「python」) |
| 日本語のタイプミス | オン | 打鍵が止まったときの見直し |
| 同じキーの重なり | オン | 「koonnnitiha」→「こんにちは」 |
| 読み違いの候補 | オン | よくある読み違い(「ふいんき」)に正しい語(雰囲気)を候補に足し，打鍵が止まると「もしかして」で示す．Tab で直す |

「修正しない語句」に入れた英字か読みを含むときは直しません(例: kubectl)．「置き換え」では，打った英字を決まった語句にします(例: pthon → Python3)．置き換えは綴りの辞書より先に使います．

## 英語と日本語

英字で打った語を英語のままにするか日本語にするかを決めます．英字入力(自動)と，ローマ字入力で英語にも読める語(make → 負け など)に使います．

| 項目 | 既定 | |
|---|---|---|
| 前の単語で判別 | オン | make・shine のように英語にも日本語にも読める単語を，前が英語なら英語，日本語なら日本語にする．ローマ字入力では前が英語のときだけ英語にする |
| 不適切な変換を避ける | オン | 「死ね」のような語を第 1 候補に出さない．英字入力(自動)では，前が日本語でなければそうした語を日本語にしない |
| 常に英語にする単語 | なし | |
| 常に日本語にする単語 | なし | |
| 判別ルール | なし | 語と前(文の頭・英語・日本語)ごとに英語か日本語かを決める |

「試す」に英字で文を打つと(語は空白で区切る)，語ごとに英語と日本語のどちらにするかを入力と同じ見分け方で出します．結果を右クリックすると，その語を一覧に足せます．一覧の語は ⇄ でもう一方の一覧に移せます．

## 記号

連続入力によるサジェスト(「->」→「→」)と，読み仮名入力によるサジェスト(「やじるし」→「→ ← ↑ ↓」)の決まりを一覧で見て，書き換え・無効化・追加ができます．既定の決まりは消さず，変えた分だけを保存します．変えた決まりには「変更あり」，足した決まりには「追加」の印が付き，変えた決まりは「既定に戻す」で戻せます．左の「有効」を外すと，その決まりを使いません．

## 除外設定

アプリごとに入力の扱いを変えます．「アプリを追加…」でアプリケーションのフォルダからアプリを選びます(バンドル ID の前方一致で決め，上にあるものほど優先します)．行を選んで上下の矢印のボタンで優先度を変えられます．既定ではエディタ(VS Code，Cursor，JetBrains，Xcode など)とターミナル(ターミナル，iTerm2，Ghostty など)を登録してあります．

| 動作 | 動き |
|---|---|
| IME を使わない | 日本語のモードでも英数のまま入れる |
| 記号を半角 | 記号とスペースを半角のまま入れる |
| コマンドを英字 | 記号を半角にし，行の頭でコマンドの名前を打って Space を押すと，その行を英字のまま流す(引用符の中と # の後ろは日本語) |

一覧は CSV で読み込み・書き出しできます．1 行は「アプリの ID,動作」で，動作は `direct`・`programming`・`terminal`(または画面の名前)です．

「エディタとターミナルでライブ変換を控える」(既定はオン)では，エディタとターミナルで，打鍵が止まるまで読みのまま見せ，識別子を打っているあいだ(読みの末尾が英数字)は変換しません．どのアプリでも，英単語に続けて大文字・数字・`_` を打ったときと，`_`・`.`・英数字のすぐあとの英字は綴りを直しません．エディタとターミナルでは，日本語の文の中にない英単語の綴りも直しません．

「ターミナルでコマンドを英字で入力」をオフにすると，コマンドを英字の動作でも行の頭を日本語にします．「Esc で英数に切り替え」をオンにすると，Vim のノーマルモードに戻るときに英数に切り替わります．既定ではオフです．

## 外観

| 項目 | 既定 | 選べる値 |
|---|---|---|
| テーマ | 標準 | 標準 / 和紙 / 北欧 / ネオン / 端末 / 高コントラスト / プラチナ / 夜のデスク |
| 候補の文字サイズ | 15 | 12〜24 |

標準はすりガラスの見た目で，ライトとダークのどちらにも合わせます．和紙・北欧・ネオン・端末・高コントラストは色と書体の違う角丸の見た目，プラチナと夜のデスクは四角い枠の古い Mac 風の見た目です．

### カスタムテーマ

「カスタムテーマを作成…」で，テーマを組み立てる画面を開きます．使っているテーマの色から始め，名前，色(背景・文字・補助の文字・選択・選択中の文字・修正の印・線)，角の丸さ，枝(曲線・直線)，書体を選びます．選んだものは画面の上の分岐図の見本にすぐ映ります．「保存」で保存してそのテーマを使い，「キャンセル」で何も変えずに閉じます．

文字と地の色が近すぎると「読みやすさ」に知らせを出し，その色の行に印を付けます．基準は既成のテーマと同じで，文字・補助の文字・選択中の文字はコントラスト比 4.5 以上，修正の印は 3 以上です．保存はできます．

一覧の行の右のボタン(または右クリック)で，編集・複製・削除ができます．「今のテーマを複製」は，使っているテーマをそのまま写したカスタムテーマを作って使います．50 個まで保存できます．

## 同期

「フォルダを選ぶ…」で選んだフォルダに，設定とユーザー辞書を `s90-sync.json` として置きます．Dropbox・Google Drive・iCloud Drive のフォルダを選ぶと，それぞれのアプリがほかの Mac に運び，s90.tokyo IME はそのファイルと突き合わせます．s90.tokyo IME 自身は通信しません．

- 設定を変えると 2 秒ほどで書き出し，ほかの Mac の変更は 1 分ごとに取り込みます．「今すぐ同期」でもすぐに突き合わせます
- 両方で変えたときは，まとまりごとにあとで変えた方を使います．ユーザー辞書は両方の語を合わせ，消した語はほかの Mac でも消えます
- 取り込んだ辞書は，辞書のファイルも同じフォルダの `s90-dictionaries` に置いて運びます．ほかの Mac では，運んだファイルが取り込んだときと同じ中身かを確かめてから使います．再読み込みすると新しい中身を運び，消した辞書はほかの Mac でも消えます．大きな辞書は届くまで時間がかかります
- まとまりごとに「同期する」「この Mac だけ」を選べます．キー配列・外観・除外設定・統計は，Mac ごとに違ってよいので既定で「この Mac だけ」です
- 同期するまとまりの中でも，「項目」を開いて印を付けた項目は，この Mac だけの値にします(例えばライブ変換だけ Mac ごとに変える)．ほかの Mac の値も変えません

| まとまり | 既定 |
|---|---|
| 入力・キー設定・変換・補正(英語と日本語を含む)・記号・ユーザー辞書・取り込んだ辞書 | 同期する |
| キー配列・外観・除外設定・統計 | この Mac だけ |

設定のファイルには形式のバージョンを書いています．古いバージョンのファイルは読み込むときに今の形に移し替えます．新しいバージョンで書いたファイルをこのバージョンで開いても，このバージョンが知らない項目は消さずに残します．

## バックアップ

「設定をエクスポート…」で，ユーザー辞書・テーマ・キー設定を含むすべての設定を JSON のファイルに保存します．「設定をインポート…」で，そのファイルからすべての設定を置き換えます．読めない項目と範囲の外の値は既定の値にします．「すべての設定を既定に戻す」はユーザー辞書を残して，ほかの設定を既定に戻します．

## 情報

バージョンと，s90.tokyo IME が利用しているオープンソースソフトウェアとモデルの謝辞(著作権表示とライセンス)を出します．

## まだ無い項目と，入れない項目
