---
title: はじめに
description: s90.tokyo IME を macOS に入れて最初の文を変換するまで
---

1. リポジトリを手元に置き，`make install-macos` を実行します．Xcode 26 と XcodeGen が要ります
2. システム設定 > キーボード > 入力ソース を開き，「s90.tokyo IME」の「ひらがな」が入っていることを確かめます．無ければ「+」から日本語を選んで足します
3. メニューバーの入力メニューから「s90.tokyo IME」を選びます
4. テキストエディットなどで `kyouhaiitenkidesune` と打つと，打ちながら「今日はいい天気ですね」と表示されます．Enter で確定します
5. Space を押すと候補を選べます．文節が 2 つ以上あると，文節ごとの列に候補が並びます．←→ で文節を移り，↑↓ で候補を選びます

設定はメニューバーの「あ」のメニューから変えられます．
