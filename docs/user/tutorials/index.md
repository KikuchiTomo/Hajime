---
title: はじめに
description: はじめを macOS に入れて最初の文を変換するまで
---

1. リポジトリを手元に置き，`make install-macos` を実行します．Xcode 26，XcodeGen，Apple Development の証明書が要ります
2. 一度ログアウトしてログインし直します(初めて入れたときだけ)
3. システム設定 > キーボード > 入力ソース を開き，「+」から日本語を選び，「はじめ」を足します
4. メニューバーの入力メニューから「はじめ」を選びます
5. テキストエディットなどで `kyouhaiitenkidesune` と打つと，打ちながら「今日はいい天気ですね」と表示されます．Enter で確定します
6. Space を押すと候補を選べます．文節が 2 つ以上あると，文節ごとの列に候補が並びます．←→ で文節を移り，↑↓ で候補を選びます

初めて入れて起動したときは，初期設定の窓が 1 回だけ開きます．英数とかなの切り替え・自動補正・外観・ライブ変換・候補の出し方・入力する文字・便利な機能の順に，左の実演を見ながら選びます．推奨の値を選んだ状態で開くので，そのまま「次へ」で進めても使えます．「あとで設定する」で閉じても，設定の画面の「情報」にある「初期設定をやり直す」で開き直せます．

設定はメニューバーの「あ」のメニューから変えられます．

入力メニューに出す名前は，入れるときに `make install-macos NAME="好きな名前"` で変えられます．名前はアプリの中に書き込むため，設定の画面からは変えられません．変えたあとは一度ログアウトしてログインし直してください．
