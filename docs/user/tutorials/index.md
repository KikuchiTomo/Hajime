---
title: はじめに
description: s90.tokyo IME を macOS に入れて最初の文を変換するまで
---

1. リポジトリを手元に置き，`make install-macos` を実行します．Xcode 26，XcodeGen，Apple Development の証明書が要ります
2. 一度ログアウトしてログインし直します(初めて入れたときだけ)
3. システム設定 > キーボード > 入力ソース を開き，「+」から日本語を選び，「s90.tokyo IME」を足します
4. メニューバーの入力メニューから「s90.tokyo IME」を選びます
5. テキストエディットなどで `kyouhaiitenkidesune` と打つと，打ちながら「今日はいい天気ですね」と表示されます．Enter で確定します
6. Space を押すと候補を選べます．文節が 2 つ以上あると，文節ごとの列に候補が並びます．←→ で文節を移り，↑↓ で候補を選びます

設定はメニューバーの「あ」のメニューから変えられます．
