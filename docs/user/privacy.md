---
title: データの扱い
description: はじめが保存するデータと，その保存場所
---

はじめは，入力した文字を端末の外に送信しません．通信も行いません．
かな漢字変換と打ち間違いの補正は，すべてパソコンの中で処理します．

## 保存するデータ

| データ | 内容 |
|---|---|
| 設定 | 設定画面で変更した値とユーザー辞書 |
| 学習 | 確定した候補から学んだ内容 |
| 統計 | 確定や補正の回数だけ．入力した文字は記録しません |
| 取り込んだ辞書 | 辞書の取り込みで追加した辞書 |

学習と統計は，設定画面で削除できます．統計は記録を止めることもできます．

## 保存場所

| OS | 場所 |
|---|---|
| macOS | `~/Library/Containers/men.haji.inputmethod.Hajime/` |
| Windows | 設定は `%APPDATA%\haji.men\IME\`，そのほかは `%LOCALAPPDATA%\haji.men\IME\` |

同期を設定したときだけ，指定したフォルダに設定と辞書を書き出します．フォルダの中身をほかのパソコンに運ぶのは，Dropbox などのアプリです．
